### 정렬의 정의

- 특정 기준으로 요소의 크기를 비교해 **오름차순 또는 내림차순**으로 배치하는 것
- 정렬 가능한 Collection
  - 배열, List 계열
  - Set에서는 **SortedSet** 계열
  - Map에서는 **SortedMap** 계열 (key 기준)
- `List<T>` 정렬: `Collections.sort(List<T> list)`

```java
List<String> names = Arrays.asList("Hi", "Java", "World", "Welcome");
Collections.sort(names);
System.out.println(names);  // [Hi, Java, Welcome, World]
```

### SmartPhone 정렬 — 왜 안 될까

- `Collections.sort(phones)`는 컴파일 에러
- `sort`의 선언이 `<T extends Comparable<? super T>> void sort(List<T> list)` → **Comparable을 구현한 타입만** 정렬 가능
- SmartPhone은 크기를 비교할 수 있는 기준이 없었던 것
- 언제나 정렬 가능한 요소들: `String`, `Integer` 등은 이미 `Comparable<String>`, `Comparable<Integer>`를 구현

### Comparable

```java
public interface Comparable<T> {
    public int compareTo(T o);
}
```

- `compareTo` 반환값의 **부호**가 중요 (크기는 상관없음)

| 반환값 | 의미 |
|---|---|
| 양수 | 자리 바꿈 |
| 음수 | 자리 유지 |
| 0 | 동일 위치 |

- 이미 비교 기준이 있는 타입이면 그것을 **재사용** (`String.compareTo`)
- 한계: 클래스에 기준이 하나로 고정됨 → 평생 번호로만 정렬해야 하나?

### Comparator의 활용

- 객체가 Comparable을 구현하지 않았거나, **다른 기준(사용자 정의 알고리즘)** 으로 정렬하려는 경우
  - 예: String을 알파벳 순이 아니라 **글자 수** 순으로
- `sort(List<T> list, Comparator<? super T> c)`

```java
public interface Comparator<T> {
    int compare(T o1, T o2);   // 부호 규칙은 compareTo와 같음
}
```

- 1회성으로 쓸 Comparator는 클래스를 따로 만들기 아까움 → **익명 내부 클래스**(클래스 정의 + 객체 생성을 한 번에) 또는 **람다 표현식**

```java
import java.util.*;

public class SortTest {
    static class SmartPhone implements Comparable<SmartPhone> {
        String number;
        SmartPhone(String number) { this.number = number; }

        @Override
        public int compareTo(SmartPhone o) {
            return this.number.compareTo(o.number);   // String의 비교 기준 재사용
        }

        @Override
        public String toString() { return "전화 번호: " + number; }
    }

    static class StringLengthComparator implements Comparator<String> {
        @Override
        public int compare(String o1, String o2) {
            return Integer.compare(o1.length(), o2.length());
        }
    }

    public static void main(String[] args) {
        List<String> names = Arrays.asList("Hi", "Java", "World", "Welcome");
        Collections.sort(names);
        System.out.println(names);  // [Hi, Java, Welcome, World]

        // Comparable
        List<SmartPhone> phones = Arrays.asList(new SmartPhone("010"), new SmartPhone("011"), new SmartPhone("000"));
        Collections.sort(phones);
        System.out.println(phones); // [전화 번호: 000, 전화 번호: 010, 전화 번호: 011]

        // Comparator 클래스
        Collections.sort(names, new StringLengthComparator());
        System.out.println(names);  // [Hi, Java, World, Welcome]

        // 익명 내부 클래스: 길이 내림차순
        Collections.sort(names, new Comparator<String>() {
            @Override
            public int compare(String o1, String o2) {
                return Integer.compare(o2.length(), o1.length());
            }
        });
        System.out.println(names);  // [Welcome, World, Java, Hi]

        // 람다 표현식: 길이 오름차순
        Collections.sort(names, (o1, o2) -> Integer.compare(o1.length(), o2.length()));
        System.out.println(names);  // [Hi, Java, World, Welcome]
    }
}
```
