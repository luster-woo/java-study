## 출력 예측

### 출력 1 · List의 remove 함정

```java
List<Integer> list = new ArrayList<>(List.of(10, 20, 30, 40));
list.remove(1);
list.remove(Integer.valueOf(40));
list.add(0, 5);
System.out.println(list + " " + list.size());
```

**답**

```
[5, 10, 30] 3
```

| 코드 | 결과 | 이유 |
|---|---|---|
| `remove(1)` | `[10, 30, 40]` | int → **인덱스** 1(값 20) 삭제 |
| `remove(Integer.valueOf(40))` | `[10, 30]` | Integer 객체 → **값** 40 삭제 |
| `add(0, 5)` | `[5, 10, 30]` | 0번 자리에 끼워 넣기 (뒤가 밀림) |

`remove(int index)`와 `remove(Object o)`가 **오버로딩**돼 있어서 int를 넘기면 인덱스로 처리된다.

### 출력 2 · Stream 체이닝

```java
List<String> words = List.of("spring", "java", "jpa", "security", "jwt");
System.out.println(words.stream()
        .filter(w -> w.startsWith("j"))
        .map(String::toUpperCase)
        .sorted()
        .collect(Collectors.joining(",")));
System.out.println(words.stream().mapToInt(String::length).max().getAsInt());
```

**답**

```
JAVA,JPA,JWT
8
```

한 단계씩 :

```
[spring, java, jpa, security, jwt]
 → filter(j로 시작)  : [java, jpa, jwt]
 → map(대문자)       : [JAVA, JPA, JWT]
 → sorted()          : [JAVA, JPA, JWT]   (두 번째 글자 A < P < W)
 → joining(",")      : "JAVA,JPA,JWT"
```

- 두 번째 줄 : 길이로 바꾸면 [6, 4, 3, 8, 3] → 최댓값 8 (security)
- `max()`는 OptionalInt → `getAsInt()`로 꺼냄 (비어 있으면 에러라 실무에선 `orElse` 권장)

### 출력 3 · Map 메서드

```java
Map<String, Integer> m = new HashMap<>();
m.put("a", 1);
m.put("a", m.get("a") + 1);
m.putIfAbsent("a", 100);
m.merge("b", 5, Integer::sum);
m.merge("b", 5, Integer::sum);
System.out.println(m.get("a") + " " + m.get("b") + " " + m.getOrDefault("c", 0));
```

**답**

```
2 10 0
```

| 코드 | a | b | 이유 |
|---|---|---|---|
| `put("a", 1)` | 1 | - | |
| `put("a", 1 + 1)` | 2 | - | 같은 key → **덮어쓰기** |
| `putIfAbsent("a", 100)` | 2 | - | 이미 있으면 **무시** |
| `merge("b", 5, sum)` | 2 | 5 | 없으면 5 넣기 |
| `merge("b", 5, sum)` | 2 | 10 | 있으면 기존값 + 5 |
| `getOrDefault("c", 0)` | | | 없으면 0 |

### 출력 4 · Optional

```java
Optional<String> o = Optional.of("jpa");
System.out.println(o.map(String::length).orElse(-1));
System.out.println(o.filter(s -> s.length() > 5).orElse("short"));
System.out.println(Optional.empty().isPresent());
```

**답**

```
3
short
false
```

- `map` : 값이 있으니 "jpa" → 3. orElse는 쓰이지 않음
- `filter` : 길이 3은 5보다 작음 → **빈 Optional**이 됨 → orElse 값 "short"
- `Optional.empty()` : 빈 상자 → isPresent() false

## 버그 찾기

### 버그 1 · 짝수 지우기

```java
List<Integer> nums = new ArrayList<>(List.of(1, 2, 3, 4));
for (Integer n : nums) {
    if (n % 2 == 0) nums.remove(n);
}
```

**문제점**

- 향상된 for문으로 **도는 도중에 리스트를 수정**하면 `ConcurrentModificationException`
- (참고 : 여기서 `n`은 Integer라 `remove(Object)`로 값 삭제는 제대로 호출됨. 문제는 반복 중 수정)

**수정**

```java
nums.removeIf(n -> n % 2 == 0);   // Predicate 람다
```

### 버그 2 · 같은데 다르다고 나옴

```java
Integer a = 1000;
Integer b = 1000;
if (a == b) { ... }   // false
```

**문제점**

- Integer는 **객체** → `==`는 같은 객체(주소)인지 비교
- Java는 **-128 ~ 127**만 미리 만들어 두고 재사용(캐시) → 1000은 매번 새 객체 → false
- 127이었다면 true가 나와서 테스트에선 멀쩡해 보이다가 큰 값에서 터지는 무서운 버그

**수정:** `a.equals(b)` → Wrapper끼리는 **무조건 equals**

## 빈칸 채우기

### 빈칸 1 · 단어 개수 세기

```java
map.put(w, map.getOrDefault(w, 0) + 1);
// 또는
map.merge(w, 1, Integer::sum);
```

- `map.get(w) + 1`로 쓰면 처음 나온 단어는 get이 null → **언박싱하다가 NullPointerException**
- 그래서 없을 때 0을 주는 `getOrDefault`

### 빈칸 2 · 정렬 기준 두 개

```java
list.sort(Comparator.comparingInt(Student::score).reversed()
        .thenComparing(Student::name));
```

- `comparingInt(score)` : 점수 오름차순 → `reversed()` : 내림차순으로
- `thenComparing(name)` : 점수가 같으면 이름 오름차순

⚠️ `reversed()`는 **그때까지 만든 기준 전체**를 뒤집는다

```java
// ❌ 잘못된 예 : 이름까지 붙인 뒤 reversed → 점수 오름차순 + 이름 내림차순이 됨
Comparator.comparingInt(Student::score).thenComparing(Student::name).reversed()

// ⭕ 두 번째 기준만 내림차순으로 하고 싶으면 괄호로 따로 만들어 넣기 (D5P3 풀이 참고)
.thenComparing(Comparator.comparingInt(Student::kor).reversed())
```

## 핵심 정리

| 함정 | 기억할 것 |
|---|---|
| `List<Integer>.remove(1)` | 인덱스 삭제. 값은 `Integer.valueOf(1)` |
| Stream | filter → map → sorted → 최종 작업 순서로 따라가기 |
| `max()`, `findFirst()` | Optional 계열 → `orElse`로 꺼내기 |
| `put` / `putIfAbsent` / `merge` | 덮어쓰기 / 없을 때만 / 없으면 넣고 있으면 합치기 |
| `map.get(없는키) + 1` | null 언박싱 → NPE. `getOrDefault` |
| Optional `filter` 실패 | 빈 Optional → orElse 값 |
| 반복 중 remove | ConcurrentModificationException → `removeIf` |
| Integer `==` | -128~127만 true → **equals** |
| `reversed()` | 앞의 기준 전체를 뒤집음 → 위치 주의 |
