### 함수형 프로그래밍

- 객체지향 Java: **클래스·메서드 이름과 구조**가 중요 → "Comparator의 compare가 필요해"
- 함수형 언어: 함수의 **형태(구조)** 가 중요하고 이름은 불필요 → "파라미터 두 개가 들어와서 int가 반환돼"
- Java에서는 함수의 형태 = **함수형 인터페이스**, 구현 = **람다식**

### 표준 API 종류 (java.util.function)

- 자주 쓰는 함수 구조를 표준 interface로 미리 정의
- 주로 메서드·생성자의 **파라미터로 Lambda 식을 넘기기 위함**

| 계열 | parameter | return | 메서드 | 비고 |
|---|---|---|---|---|
| **Runnable** | X | X | `void run()` | 단순 실행 |
| **Consumer** | O | X | `void accept(T)` | 소비자 |
| **Supplier** | X | O | `T get()` | 공급자 |
| **Function** | O | O | `R apply(T)` | 파라미터를 **새로운 타입으로 변환**해 리턴 |
| **Operator** | O | O | `T XXX(T)` | 파라미터를 연산해 **같은 타입**으로 리턴 |
| **Predicate** | O | boolean | `boolean test(T)` | 파라미터를 조사해 true/false 결정 |

- 표기 규칙: **P / Q** = `Int`, `Long`, `Double`(인터페이스 이름 부분), **p / q** = `int`, `long`, `double`(값 타입)
- 접두사 **Bi** = 파라미터가 2개

### Consumer 계열 — 파라미터 소비

| 인터페이스 | 메서드 | 설명 |
|---|---|---|
| `Consumer<T>` | `void accept(T t)` | T 객체를 받아 소비 |
| `BiConsumer<T, U>` | `void accept(T t, U u)` | T, U 객체를 받아 소비 |
| `PConsumer` | `void accept(p value)` | p 값을 받아 소비 |
| `ObjPConsumer<T>` | `void accept(T t, p value)` | T 객체와 p 값을 받아 소비 |

### Supplier 계열 — 리턴 값 공급

| 인터페이스 | 메서드 | 설명 |
|---|---|---|
| `Supplier<T>` | `T get()` | T 객체 리턴 |
| `PSupplier` | `p getAsP()` | p 값 리턴 (P에 `Boolean` 포함) |

### Function 계열 — 파라미터로 리턴 값 생성

- 주로 파라미터로 연산한 뒤 **원하는 타입으로** 반환

| 인터페이스 | 메서드 | 설명 |
|---|---|---|
| `Function<T, R>` | `R apply(T t)` | T를 받아 R 리턴 |
| `BiFunction<T, U, R>` | `R apply(T t, U u)` | T, U를 받아 R 리턴 |
| `PFunction<R>` | `R apply(p value)` | p를 받아 R 리턴 |
| `PToQFunction` | `q applyAsQ(p value)` | p를 받아 q 리턴 |
| `ToPFunction<T>` | `p applyAsP(T t)` | T를 받아 p 리턴 |
| `ToPBiFunction<T, U>` | `p applyAsP(T t, U u)` | T, U를 받아 p 리턴 |

### Operator 계열 — 같은 타입으로 연산 결과 리턴

- Function과 비슷(파라미터·리턴 있음), 차이는 **연산 후 동일한 타입으로 리턴**

| 인터페이스 | 메서드 | 설명 |
|---|---|---|
| `UnaryOperator<T>` (extends `Function<T, T>`) | `T apply(T t)` | T를 받아 T 리턴 |
| `BinaryOperator<T>` (extends `BiFunction<T, T, T>`) | `T apply(T t1, T t2)` | T 두 개를 받아 T 리턴 |
| `PUnaryOperator` | `p applyAsP(p)` | p를 받아 p 리턴 |
| `PBinaryOperator` | `p applyAsP(p, p)` | p 두 개를 받아 p 리턴 |

### Predicate 계열 — 파라미터로 판단

| 인터페이스 | 메서드 | 설명 |
|---|---|---|
| `Predicate<T>` | `boolean test(T t)` | T를 받아 boolean 리턴 |
| `BiPredicate<T, U>` | `boolean test(T t, U u)` | T, U를 받아 boolean 리턴 |
| `PPredicate` | `boolean test(p value)` | p를 받아 boolean 리턴 |

```java
import java.util.*;
import java.util.function.*;

public class FuncTest {
    public static void main(String[] args) {
        // Runnable
        Runnable r = () -> System.out.println("run");
        r.run();                                              // run

        // Consumer
        Consumer<String> consumer = x -> System.out.println(x);
        consumer.accept("Hello");                             // Hello
        ObjIntConsumer<String> consumer2 = (name, repeat) -> {
            for (int i = 0; i < repeat; i++) System.out.println(name);
        };
        consumer2.accept("홍길동", 2);                         // 홍길동 (2번)

        // Supplier
        Supplier<String> supplier = () -> "Hello";
        System.out.println(supplier.get());                   // Hello
        IntSupplier dice = () -> new Random().nextInt(6);
        System.out.println(dice.getAsInt() < 6);              // true (0~5 중 하나)

        // Function: 문자열 → 글자 수
        Function<String, Integer> function = src -> src.length();
        System.out.println(function.apply("Hello"));          // 5
        ToIntBiFunction<String, String> function2 = (s1, s2) -> Integer.parseInt(s1) + Integer.parseInt(s2);
        System.out.println(function2.applyAsInt("4", "5"));   // 9

        // Operator: 제곱, 최댓값
        UnaryOperator<Double> operator = x -> Math.pow(x, 2);
        System.out.println(operator.apply(10.0));             // 100.0
        DoubleBinaryOperator operator2 = (x, y) -> Math.max(x, y);
        System.out.println(operator2.applyAsDouble(100, 200)); // 200.0

        // Predicate: "Java" 포함 여부
        Predicate<String> predicate = name -> name.contains("Java");
        System.out.println(predicate.test("JavaScript"));     // true
        DoublePredicate predicate2 = num -> num > 0.5;
        System.out.println(predicate2.test(0.7));             // true
    }
}
```

> 참고: 교재 표에서 바로잡을 곳 — `BiConsumer`의 시그니처는 `accept(T t, U u)`, `ToPFunction<T>` 설명은 "T 타입을 받아 p 타입으로 리턴", `UnaryOperator`의 abstract 메서드는 `T apply(T t)`(`identity()`는 같은 값을 그대로 돌려주는 static 메서드), `BiPredicate`는 타입 파라미터가 `<T, U>` 두 개.

### Optional\<T\> — T 타입 객체의 wrapper

- 객체가 **있을 수도, 없을(null) 수도 있는 상태**를 나타내는 객체
  - `NullPointerException`에 적극적으로 대처
  - `java.util.function`이 아니라 `java.util` 패키지
- 기존 방식: 파라미터가 null일 수 있다는 걸 놓치기 쉬움 → 직접 `if (str != null)` 체크
- Optional 방식: 타입 자체가 "없을 수 있음"을 드러냄 → `isPresent()`로 확인

| 메서드 | 설명 |
|---|---|
| `T get()` | 값 리턴, 값이 없으면 예외 |
| `void ifPresent(Consumer<? super T>)` | 값이 있으면 consumer로 소비, 없으면 동작 안 함 |
| `T orElse(T other)` | 값 또는 (없으면) other 리턴 |
| `T orElseGet(Supplier<? extends T>)` | 값 또는 (없으면) Supplier가 공급한 값 리턴 |
| `T orElseThrow(Supplier<? extends X>)` | 값 또는 (없으면) Supplier가 만든 예외 발생 |

```java
import java.util.*;

public class OptionalTest {
    static void useString(Optional<String> str) {
        if (str.isPresent()) {
            System.out.println(str.get() + " : " + str.get().length());
        } else {
            System.out.println("str is empty");
        }
    }

    public static void main(String[] args) {
        useString(Optional.of("Java"));          // Java : 4
        useString(Optional.ofNullable(null));    // str is empty

        Optional<String> some = Optional.of("Hi");
        Optional<String> none = Optional.empty();
        some.ifPresent(s -> System.out.println("값: " + s));   // 값: Hi
        none.ifPresent(s -> System.out.println("값: " + s));   // (실행 안 됨)
        System.out.println(none.orElse("기본값"));              // 기본값
        System.out.println(none.orElseGet(() -> "공급값"));     // 공급값
        try {
            none.orElseThrow(() -> new IllegalStateException("값 없음"));
        } catch (IllegalStateException e) {
            System.out.println(e.getMessage());                 // 값 없음
        }
        try {
            none.get();
        } catch (NoSuchElementException e) {
            System.out.println(e.getClass().getSimpleName());   // NoSuchElementException
        }
    }
}
```

> 참고: 교재는 `get()`이 값이 없을 때 `NullPointerException`을 낸다고 했으나 실제로는 `NoSuchElementException`이다(위 실행 결과).

### API에서 사용된 표준 함수형 인터페이스

| API | 메서드 | 쓰인 인터페이스 |
|---|---|---|
| `Map` | `forEach(BiConsumer)` | BiConsumer |
| `Map` | `computeIfAbsent(K, Function)` | Function |
| `Map` | `computeIfPresent(K, BiFunction)` | BiFunction |
| `Optional` | `orElseGet(Supplier)` | Supplier |
| `Optional` | `ifPresentOrElse(Consumer, Runnable)` | Consumer, Runnable |
| `List` | `replaceAll(UnaryOperator)` | UnaryOperator |
| `Collection` | `removeIf(Predicate)` | Predicate |

```java
import java.util.*;

public class ApiFuncTest {
    public static void main(String[] args) {
        Map<String, Integer> map = new TreeMap<>(Map.of("a", 1, "b", 2));
        map.forEach((k, v) -> System.out.println(k + "=" + v));   // a=1 / b=2
        map.computeIfAbsent("c", k -> 3);
        map.computeIfPresent("a", (k, v) -> v + 10);
        System.out.println(map);                                    // {a=11, b=2, c=3}

        List<Integer> list = new ArrayList<>(List.of(1, 2, 3, 4, 5));
        list.replaceAll(n -> n * 10);
        list.removeIf(n -> n > 30);
        System.out.println(list);                                   // [10, 20, 30]

        Optional.empty().ifPresentOrElse(
            v -> System.out.println(v),
            () -> System.out.println("비어 있음"));                  // 비어 있음
    }
}
```
