## 구현 요구사항

- 회원: 등록, 조회
- 상품: 등록, 수정, 조회
- 주문: 상품 주문, 주문 내역 조회, 주문 취소

**예제를 단순화하려고 구현 X**: 로그인·권한 관리 / 파라미터 검증·예외 처리 / 상품은 **도서만** / 카테고리 / 배송 정보

## 애플리케이션 아키텍처 — 계층형 구조

```
 [web/controller] ──▶ [service] ──▶ [repository] ──▶ DB
        │                 │               │
        └──────────── [domain] ───────────┘   (엔티티: 모든 계층에서 사용)
```

| 계층 | 역할 |
|---|---|
| **controller, web** | 웹 계층 |
| **service** | 비즈니스 로직, **트랜잭션** 처리 |
| **repository** | **JPA를 직접 사용**하는 계층, 엔티티 매니저 사용 |
| **domain** | 엔티티가 모여 있는 계층, 모든 계층에서 사용 |

- 강의 방침: 컨트롤러가 단순 조회는 리포지토리를 바로 불러도 되는 유연한 구조(단방향 의존은 유지)

### 패키지 구조

```
jpabook.jpashop
├─ domain
├─ exception
├─ repository
├─ service
└─ web
```

### 개발 순서

**서비스·리포지토리 계층 개발 → 테스트 케이스로 검증 → 마지막에 웹 계층 적용**
