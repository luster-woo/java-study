## 1. 프로젝트 생성

[start.spring.io](https://start.spring.io)

- Project: **Gradle - Groovy**, Spring Boot **3.x 최신**, Java **17 또는 21**
- Dependencies: **web, thymeleaf, jpa, h2, lombok, validation** (validation은 영상에 없음 — 꼭 추가)
- groupId `jpabook`, artifactId `jpashop`

### build.gradle (강의 소스)

```groovy
plugins {
    id 'java'
    id 'org.springframework.boot' version '3.4.4'
    id 'io.spring.dependency-management' version '1.1.7'
}
group = 'jpabook'
java { toolchain { languageVersion = JavaLanguageVersion.of(17) } }

configurations { compileOnly { extendsFrom annotationProcessor } }

dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-data-jpa'
    implementation 'org.springframework.boot:spring-boot-starter-thymeleaf'
    implementation 'org.springframework.boot:spring-boot-starter-validation'
    implementation 'org.springframework.boot:spring-boot-starter-web'
    implementation 'com.github.gavlyukovskiy:p6spy-spring-boot-starter:1.10.0'  // 쿼리 파라미터 로그

    compileOnly 'org.projectlombok:lombok'
    runtimeOnly 'com.h2database:h2'
    annotationProcessor 'org.projectlombok:lombok'
    testImplementation 'org.springframework.boot:spring-boot-starter-test'
    testRuntimeOnly 'org.junit.platform:junit-platform-launcher'
}
tasks.named('test') { useJUnitPlatform() }
```

## 3. View 환경 설정 (Thymeleaf)

- 뷰 이름 매핑: `resources/templates/` + **{ViewName}** + `.html`

```java
@Controller
public class HelloController {
    @GetMapping("hello")
    public String hello(Model model) {
        model.addAttribute("data", "hello!!");
        return "hello";               // → templates/hello.html
    }
}
```

```html
<p th:text="'안녕하세요. ' + ${data}">안녕하세요. 손님</p>
```

- 정적 페이지: `static/index.html`
- 참고: `spring-boot-devtools`를 넣으면 html만 Recompile(Build → Recompile)해서 서버 재시작 없이 반영

## 4. H2 데이터베이스

- Spring Boot 3.x는 **H2 2.1.214 이상**
- 최초 1번 `jdbc:h2:~/jpashop`으로 접속해 `~/jpashop.mv.db` 생성 → 이후 **`jdbc:h2:tcp://localhost/~/jpashop`**
- 영상의 `;MVCC=TRUE` 옵션은 **제거** (H2 1.4.198부터 없어져서 붙이면 오류)

## 5. JPA와 DB 설정 — application.yml (강의 소스)

```yaml
spring:
  datasource:
    url: jdbc:h2:tcp://localhost/~/jpashop
    username: sa
    password:
    driver-class-name: org.h2.Driver

  jpa:
    hibernate:
      ddl-auto: create          # 실행 시점에 drop 후 다시 생성
    properties:
      hibernate:
#        show_sql: true          # System.out 출력 → 쓰지 말 것
        format_sql: true

logging.level:
  org.hibernate.SQL: debug      # logger로 SQL 출력
#  org.hibernate.orm.jdbc.bind: trace   # Boot 3 / Hibernate 6: 바인딩 파라미터
```

- **yml은 띄어쓰기 2칸으로 계층**을 만든다 (`spring:` 0칸 → `datasource:` 2칸 → `url:` 4칸). 틀리면 설정이 안 먹음
- **모든 로그는 가급적 로거로**: `show_sql`(System.out) 대신 `org.hibernate.SQL: debug`
- `persistence.xml`도, `LocalContainerEntityManagerFactoryBean`도 없다 — 스프링 부트가 자동 설정

### 동작 확인 코드 (나중에 지움)

```java
@Entity @Getter @Setter
public class Member {
    @Id @GeneratedValue
    private Long id;
    private String username;
}

@Repository
public class MemberRepository {
    @PersistenceContext
    EntityManager em;                    // 스프링 부트가 주입
    public Long save(Member member) {
        em.persist(member);
        return member.getId();           // 커맨드와 쿼리 분리: 저장 후 id 정도만 반환
    }
    public Member find(Long id) { return em.find(Member.class, id); }
}
```

```java
@SpringBootTest
class MemberRepositoryTest {
    @Autowired MemberRepository memberRepository;

    @Test
    @Transactional          // 테스트에 붙으면 끝나고 롤백
    @Rollback(false)        // 눈으로 DB 확인하고 싶을 때
    void testMember() {
        Member member = new Member();
        member.setUsername("memberA");
        Long savedId = memberRepository.save(member);
        Member findMember = memberRepository.find(savedId);

        assertThat(findMember.getId()).isEqualTo(member.getId());
        assertThat(findMember).isEqualTo(member);   // 같은 트랜잭션 = 같은 영속성 컨텍스트 → 동일성 보장
    }
}
```

- 트랜잭션 없이 `persist`하면 `No EntityManager with actual transaction available` 오류
- 마지막 `isEqualTo(member)`가 true인 이유: 1차 캐시 ([JPA 기본편 3장](../jpa-basic/03_영속성_관리.md))

> 참고: PDF 예제는 `jakarta.transaction.Transactional`을 import하지만, 강의 소스의 서비스·테스트는 모두 **`org.springframework.transaction.annotation.Transactional`** 을 쓴다. 스프링 것이 `readOnly` 같은 옵션이 더 많으니 이걸 쓰자.

> **주의**: 2장 엔티티 개발을 시작하기 전에 `jpabook.jpashop.Member`, `MemberRepository`, `MemberRepositoryTest`는 **반드시 삭제** (domain.Member와 충돌). 그래도 이상하면 `build` 폴더 삭제 후 재실행.

## 6. 쿼리 파라미터 로그 남기기

| 방법 | 설정 |
|---|---|
| Hibernate 6 (Boot 3) | `logging.level.org.hibernate.orm.jdbc.bind: trace` |
| Hibernate 5 (Boot 2) | `logging.level.org.hibernate.type: trace` |
| 외부 라이브러리 **p6spy** | `implementation 'com.github.gavlyukovskiy:p6spy-spring-boot-starter:<버전>'` 추가만 하면 `?` 자리에 값이 채워진 SQL 출력 |

- p6spy 버전: 메뉴얼 기준 **Boot 3.x → 1.12.1, Boot 4.x → 2.0.0** (강의 소스는 1.10.0)
- 외부 로그 라이브러리는 시스템 자원을 쓰므로 **개발 단계에선 편하게, 운영 적용은 성능 테스트 후**
