### 제한자(modifier)

- 클래스, 변수, 메서드 선언부에 함께 쓰여 **부가적인 의미**를 부여
- 종류
  - **접근 제한자**: `public`, `protected`, `(default = package)`, `private`
  - 그 외 제한자

| 제한자 | 의미 |
|---|---|
| `static` | 클래스 레벨의 요소 설정 |
| `final` | 요소를 더 이상 수정할 수 없게 함 |
| `abstract` | 추상 메서드 및 추상 클래스 작성 |
| `synchronized` | 멀티스레드에서의 동기화 처리 |

- 하나의 대상에 여러 제한자를 조합할 수 있으나 **접근 제한자는 하나만** 사용 가능
- 순서는 무관 — 일반적으로 접근 제한자를 맨 앞에

### final

- 마지막, 더 이상 바뀔 수 없음

| 대상 | 의미 |
|---|---|
| final class | 더 이상 확장할 수 없음 → **상속 금지** → 오버라이드 방지 (예: `String`, `Math`) |
| final method | 더 이상 재정의할 수 없음 → **overriding 금지** |
| final variable | 더 이상 값을 바꿀 수 없음 |

```java
final class PerfectClass {}
class FinalClassTest extends PerfectClass {}   // 컴파일 에러: cannot inherit from final PerfectClass

class ParentClass {
    public final void finalMethod() {}
}
class FinalMethodTest extends ParentClass {
    public void finalMethod() {}               // 컴파일 에러: cannot override ... overridden method is final
}

class FinalParam {
    public void finalParameterTest(final String name) {
        System.out.println(name);
        name = "hong";                         // 컴파일 에러: final parameter name may not be assigned
    }
}
```

- final은 확장을 막는다기보다 **실수하지 않게 도와주는 것**

### blank final과 static final

- **blank final** — 값이 할당되지 않은 final 멤버 변수
  - final 멤버에 초기값을 주면 모든 객체가 같은 값을 써야 함 (모두 O형?)
  - 객체가 생성되면 값을 바꿀 기회가 없으므로 **생성자에서 1회** 초기화
  - 생성자에서 초기화를 **강제**하는 역할
- **static final**
  - `final`만 있으면 객체마다 갖는 값이라 공용성이 없음
  - 진정한 **상수**는 객체와 무관하게 모두가 공유하는 값 (`Math.PI`, `Math.E`, ...)

```java
public class FinalTest {
    public static void main(String[] args) {
        Human h1 = new Human("O");
        Human h2 = new Human("A");
        System.out.println(h1.bloodType + ", " + h2.bloodType);  // O, A
        System.out.println(Human.EYES);                         // 2
        System.out.println(Math.PI);                            // 3.141592653589793
    }
}

class Human {
    final String bloodType;               // blank final: 선언 시 값 없음
    static final int EYES = 2;            // 진정한 상수: 모든 객체가 공용

    Human(String bloodType) {
        this.bloodType = bloodType;       // 생성자에서 1회만 초기화
    }
}
```

### 문제 — 출력되는 배열의 크기는?

```java
public class LoadingSequenceTest {
    private static LoadingSequenceTest lst = new LoadingSequenceTest();
    private static int SIZE = 10;
    private int[] array = null;

    public static LoadingSequenceTest getInstance() {
        return lst;
    }

    private LoadingSequenceTest() {
        array = new int[SIZE];   // 멤버 변수의 초기화
    }

    public static void main(String[] args) {
        LoadingSequenceTest lst = LoadingSequenceTest.getInstance();
        System.out.println(lst.array.length);  // 0
    }
}
```

- static 변수는 **선언된 순서대로** 초기화됨
  1. `lst = new LoadingSequenceTest()` 실행 → 생성자 안에서 `SIZE`는 아직 기본값 `0` → `new int[0]`
  2. 그 다음에 `SIZE = 10` 대입
- 크기가 10이 되려면
  - `SIZE` 선언을 `lst` 선언보다 **위로** 옮김 → `10`
  - 또는 `private static final int SIZE = 10;` → 컴파일 시점 상수라 먼저 값이 정해짐 → `10`

### 접근 제한자(Access modifier)

- 멤버 등에 쓰여 그 요소를 **외부에서 사용할 수 있는지** 설정

| 제한자 | 같은 클래스 | 같은 패키지 | 다른 패키지의 자손 클래스 | 전체 | 사용 가능 대상 |
|---|---|---|---|---|---|
| `public` | O | O | O | O | 클래스, 생성자, 멤버 |
| `protected` | O | O | O | | 생성자, 멤버 |
| `package(default)` | O | O | | | 클래스, 생성자, 멤버 |
| `private` | O | | | | 생성자, 멤버 |

- 교재 비유 — "우리 가게"

| 제한자 | 누가 볼 수 있나 | 물건 |
|---|---|---|
| `private` | 아빠만 | 아빠 연애편지 |
| `package` | 우리 가게 안(누나 & 직원) | 냉장고 속 |
| `protected` | 다른 지역 분점의 형(자손)까지 | 레시피 |
| `public` | 손님 누구나 | 메뉴판 |

### 접근 제한자의 동작 확인

```java
package modifier.p1;

public class Parent {
    public int publicVar;
    protected int protectedVar;
    int defaultVar;
    private int privateVar;
}
```

| 사용 위치 | public | protected | default | private |
|---|---|---|---|---|
| 같은 패키지(`modifier.p1`) 일반 클래스 — `p.xxx` | O | O | O | X |
| 같은 패키지 자식 클래스 — `this.xxx` | O | O | O | X |
| 다른 패키지(`modifier.p2`) 일반 클래스 — `p.xxx` | O | X | X | X |
| 다른 패키지 자식 클래스 — `this.xxx` | O | O | X | X |

```java
package modifier.p2;

import modifier.p1.Parent;

public class ChildOther extends Parent {
    public void useMember() {
        this.publicVar = 10;
        this.protectedVar = 10;   // 다른 패키지라도 자손이면 가능
        // this.defaultVar = 10;  // 컴파일 에러: defaultVar is not public in Parent; cannot be accessed from outside package
        // this.privateVar = 10;  // 컴파일 에러: privateVar has private access in Parent
    }
}
```

### method override 조건 확인

- 부모의 제한자 범위와 **같거나 넓은** 범위로만 재정의 가능

```java
class Parent {
    protected void method() {}
}

public class OverrideRule extends Parent {
    void method() {}               // X 컴파일 에러: default는 protected보다 좁음
    // protected void method() {}  // O 같은 범위
    // public void method() {}     // O 더 넓은 범위
}
```

## 참고

- 교재 코드의 클래스 이름은 노트에서 일부 바꿨고, 단일 파일 실행(`java Xxx.java`)을 위해 `main`이 있는 클래스를 파일 맨 위에 둠.
- 교재 접근 제한자 예제는 Parent의 필드 이름(`publicVariable` 등)과 자식 클래스에서 쓰는 이름(`publicVar` 등)이 서로 다름 → 노트에서는 `publicVar` 계열로 통일함.
