## 연산자(Operator)

- **연산자(operator)** : 계산이나 처리를 수행하는 기호
- **피연산자(operand)** : 연산의 대상이 되는 값(또는 변수)
- 연산자가 여러 개면 **우선순위**에 따라 계산 → 모르면 소괄호 `()` 사용
- 종류 : 산술, 증감, 비교, 논리, 대입, 단항, 삼항 ...

### 산술 연산자

- 수학적 계산에 사용
- **정수와 정수**의 연산 → 정수
- **정수와 실수**의 연산 → 실수

| 연산자 | 설명 | 예제 |
| --- | --- | --- |
| `+` | 덧셈 | `a + b` |
| `-` | 뺄셈 | `a - b` |
| `*` | 곱셈 | `a * b` |
| `/` | 나눗셈 | `a / b` |
| `%` | 나머지 | `a % b` |

```java
int a = 7, b = 2;
System.out.println(a + b);    // 9
System.out.println(a - b);    // 5
System.out.println(a * b);    // 14
System.out.println(a / b);    // 3   (정수 / 정수 → 정수)
System.out.println(a % b);    // 1
System.out.println(a / 2.0);  // 3.5 (정수 / 실수 → 실수)
```

### 비교 연산자

- 두 값을 비교하여 참/거짓(`boolean`) 반환
- 문자열 비교는 `==` 보다 **`equals()`** 활용
- `=` 는 "같다"가 아니라 **대입** 연산자

| 연산자 | 설명 | 예제 |
| --- | --- | --- |
| `==` | 같음 | `a == b` |
| `!=` | 같지 않음 | `a != b` |
| `>` | 왼쪽 값이 큼 | `a > b` |
| `<` | 오른쪽 값이 큼 | `a < b` |
| `>=` | 왼쪽 값이 크거나 같음 | `a >= b` |
| `<=` | 오른쪽 값이 크거나 같음 | `a <= b` |
| `instanceof` | 객체가 특정 클래스의 인스턴스인지 확인 | `a instanceof b` |

```java
System.out.println(a == b);             // false
System.out.println(a != b);             // true

String s1 = "hi";
String s2 = new String("hi");
System.out.println(s1 == s2);           // false (참조(주소) 비교)
System.out.println(s1.equals(s2));      // true  (내용 비교)
System.out.println(s1 instanceof String); // true
```

### 논리 연산자

- 조건을 조합하여 참/거짓(`boolean`) 반환
- 작성 순서에 따라 효율적인 연산 가능 — **단락 평가(Short-Circuit Evaluation)** : 결과를 더 확인할 필요가 없으면 남은 조건을 연산하지 않고 넘어감

| 연산자 | 설명 | 예제 |
| --- | --- | --- |
| `&&` | 두 피연산자 모두 true일 때만 true | `a > 0 && b > 0` |
| `\|\|` | 하나라도 true이면 true | `a > 0 \|\| b > 0` |
| `!` | 결과를 반대로 | `!(a > 0)` |

```java
public class ShortCircuit {
    static boolean check(String name, boolean result) {
        System.out.println(name + " 평가");
        return result;
    }

    public static void main(String[] args) {
        System.out.println(check("A", false) && check("B", true));
        System.out.println(check("C", true) || check("D", true));
    }
}
/* 출력
A 평가
false        ← A가 false라 B는 평가하지 않음
C 평가
true         ← C가 true라 D는 평가하지 않음
*/
```

### 대입(복합) 연산자

- 변수에 값을 할당
- **복합 대입 연산자** : 산술 연산자 + 대입 연산자 축약 (오른쪽 계산 후 대입 — 순서 생각)

| 연산자 | 설명 | 예제 |
| --- | --- | --- |
| `=` | 값 할당 | `a = 10` |
| `+=` | 더하여 할당 | `a += 5` |
| `-=` | 빼고 할당 | `a -= 5` |
| `*=` | 곱하여 할당 | `a *= 5` |
| `/=` | 나누어 할당 | `a /= 5` |
| `%=` | 나눈 나머지를 할당 | `a %= 5` |

```java
int n = 10;
n += 5;  System.out.println(n);  // 15
n -= 3;  System.out.println(n);  // 12
n *= 2;  System.out.println(n);  // 24
n /= 4;  System.out.println(n);  // 6
n %= 4;  System.out.println(n);  // 2
```

### 단항 연산자

- 하나의 피연산자에만 작용
- 변수 값의 상태를 변경하거나 체크하는 데 사용

| 연산자 | 설명 | 예제 |
| --- | --- | --- |
| `+`, `-` | 부호 변경 (`+` : 영향 없음, `-` : 부호 반대) | `b = -a` |
| `++a`, `--a` | 증감 **전치** 연산 : 값을 1 증/감시키고 사용 | `++a` |
| `a++`, `a--` | 증감 **후치** 연산 : 현재 값을 사용한 뒤 1 증/감 | `a--` |
| `!` | 논리 NOT (반전) | `!isOk` |
| `~` | 비트 NOT (모든 비트 반전) | `~a` |
| `(type)a` | 데이터 타입 강제 변환 | `(int)b` |

```java
int p = 5;
System.out.println(-p);   // -5
System.out.println(++p);  // 6  (먼저 증가 → 사용)
System.out.println(p++);  // 6  (사용 → 나중에 증가)
System.out.println(p);    // 7
System.out.println(--p);  // 6
System.out.println(p--);  // 6
System.out.println(p);    // 5
System.out.println(~5);   // -6 (비트 반전: ~x == -x-1)
```

### 기타 연산자

- **삼항 연산자** `(조건식) ? (참) : (거짓)`
- `new` 연산자 (객체 생성)
- `[인덱스]` 배열 접근 연산자
- `.` 객체 멤버 접근 연산자
- 비트 연산자 ...

```java
int score = 85;
String r = score >= 60 ? "합격" : "불합격";
System.out.println(r);  // 합격
```

### 연산자 우선순위

- 대략 **괄호 → 산술 → 비교 → 논리 → 대입** 순
- 소괄호로 표현하면 가독성이 올라감

```java
System.out.println(2 + 3 * 4);            // 14
System.out.println((2 + 3) * 4);          // 20
System.out.println(1 + 2 > 2 && 3 < 4);   // true (산술 → 비교 → 논리)
```
