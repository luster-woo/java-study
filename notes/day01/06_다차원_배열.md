## 2차원 Array 만들기 #1 — 선언, 생성, 값 할당

| 단계 | 코드 |
| --- | --- |
| 선언 | `int[][] intArray;` · `int intArray[][];` · `int[] intArray[];` |
| 생성 | `intArray = new int[4][3];` |
| 값 할당 | `intArray[0][2] = 3;` |

- `intArray` 는 **`int[]` 을 저장하는 배열**

| 변수 | 변수의 타입 | 저장하는 데이터의 타입 |
| --- | --- | --- |
| `int a` | `int` | `int` 값 |
| `int[] arr` | `int[]` | `int` |
| `int[][] arr2` | `int[][]` | `int[]` (1차원 배열의 참조) |

```text
intArray ──▶ [0] ──▶ [ 0 ][ 0 ][ 3 ]     intArray[0][2] = 3
             [1] ──▶ [ 0 ][ 0 ][ 0 ]
             [2] ──▶ [ 0 ][ 0 ][ 0 ]
             [3] ──▶ [ 0 ][ 0 ][ 0 ]
          (길이 4)      (각 길이 3)
```

## 2차원 Array 만들기 #3 — 4 x ? 배열

- 1차 배열만 생성한 뒤, 필요에 따라 2차 배열을 생성
- 1차 배열의 각 칸은 `int[]` 을 저장하면 되므로 `int[3]` 이든 `int[2]` 든 상관없음 → 행마다 길이가 달라도 됨
- 2차 배열 생성 시에도 `{}` 만으로는 할당 불가

```java
int[][] intArray = new int[4][];   // 1차 배열만 생성 (각 칸은 null)
intArray[0] = new int[3];
intArray[1] = new int[2];
// intArray[2] = {1, 2, 3};        // (X) 컴파일 오류
intArray[2] = new int[]{1, 2, 3};  // (O)
```

```java
import java.util.Arrays;

public class Array2D {
    public static void main(String[] args) {
        int[][] intArray = new int[4][3];
        intArray[0][2] = 3;
        System.out.println(Arrays.deepToString(intArray));
        // [[0, 0, 3], [0, 0, 0], [0, 0, 0], [0, 0, 0]]
        System.out.println(intArray.length + " " + intArray[0].length);  // 4 3

        int[][] jagged = new int[4][];
        System.out.println(Arrays.toString(jagged));      // [null, null, null, null]
        jagged[0] = new int[3];
        jagged[1] = new int[2];
        jagged[2] = new int[]{1, 2, 3};
        System.out.println(Arrays.deepToString(jagged));
        // [[0, 0, 0], [0, 0], [1, 2, 3], null]
    }
}
```

### 문제 — 4x3 2차원 배열을 만드는 방법 중 올바르지 않은 것은?

| 코드 | 결과 |
| --- | --- |
| `int intArray[][] = new int[4][3];` | O |
| `int[] intArray2[] = new int[][3];` | **X** — 1차 배열의 길이는 생략 불가 |
| `int[][] intArray3 = new int[4][];` | O (2차 배열은 나중에 생성) |
| `int[][] intArray4 = new int[4]{1,2,3};` | **X** — 길이와 초기값 목록을 함께 쓸 수 없음 |
| `int[][] intArray5 = new int[][]{{1,2,3},{1,2,3},{1,2,3},{1,2,3}};` | O |
| `int[][] intArray6 = {{1,2,3},{1,2,3},{1,2,3},{1,2,3}};` | O |

## 다차원 배열의 메모리 사용 단계

```java
int a = 10;
int[] arr = new int[4];
int[][] arr2 = new int[2][3];
int[][] arr3 = new int[2][];
arr3[0] = new int[3];
arr3[1] = arr2;        // 어디 이상하지 않아?
arr3[1][1] = 100;
```

```text
a    [ 10 ]                              ← 기본형: 값 자체
arr  [ 0x100 ] ──▶ [0][0][0][0]
arr2 [ 0x200 ] ──▶ [0x210][0x220]
                      │      └──▶ [0][0][0]
                      └─────────▶ [0][0][0]
arr3 [ 0x300 ] ──▶ [0x310][ ? ]
                      └─────────▶ [0][0][0]
```

- `arr3[1]` 은 `int[]` 을 저장하는 칸인데 `arr2` 는 `int[][]` → **타입이 맞지 않아 컴파일 오류** (교재 질문 "어디 이상하지 않아?"의 답)
- `int[]` 을 넣어야 함 → 예: `arr3[1] = arr2[0];` 처럼 **같은 1차원 배열을 공유**하면, `arr3[1][1] = 100` 이 `arr2[0][1]` 도 바꿈

```java
int[][] m2 = new int[2][3];
int[][] m3 = new int[2][];
m3[0] = new int[3];
m3[1] = m2[0];           // 같은 int[]을 가리킴
m3[1][1] = 100;
System.out.println(Arrays.deepToString(m2));  // [[0, 100, 0], [0, 0, 0]]
System.out.println(Arrays.deepToString(m3));  // [[0, 0, 0], [0, 100, 0]]
```

### 문제 — 변수의 타입 이야기하기

```java
char c = 'A';
char[] chars = new char[3];
char[][] chars2 = new char[4][3];
```

- 각 변수의 타입 → `char`, `char[]`, `char[][]`
- `chars2` 의 요소로 `char` 를 저장할 수 있다? → **없다**, `chars2` 는 `char[]` 을 저장
- `chars2[0]` 이 참조하는 배열에는 `char` 몇 개? → **3개**
- `int` 의 100차원 배열이란? → **int 99차원 배열을 저장하는 배열**

> 참고: 교재 답안의 "chars는 char[]을 저장한다"는 `chars2` 의 오기로 보인다 — `chars` 는 `char` 를 저장하고, `char[]` 을 저장하는 것은 `chars2` 다.

## Array 순회 / 탐색

- 전체를 돌다가 X를 만나면 → X 주변 탐색
- X가 움직이면서 → X 주변 탐색

| 탐색 범위 | 살펴보는 칸 |
| --- | --- |
| 좌/우 | `(r, c-1)`, `(r, c+1)` |
| 상/하 | `(r-1, c)`, `(r+1, c)` |
| 4방 | 상·하·좌·우 |
| 8방 | 4방 + 대각선 4칸 |

```text
   좌/우          4방            8방
 . . . . .     . . . . .     . . . . .
 . . . . .     . . o . .     . o o o .
 . o X o .     . o X o .     . o X o .
 . . . . .     . . o . .     . o o o .
```

- 특정 좌표에서 주변을 탐색할 때는 **배열의 범위를 벗어나지 않기 위한 코드**(경계 검사)가 필요

### 기본 문제 — 3의 배수 개수와 합 (Array_07)

- 5x5 2차원 배열에서 3의 배수의 개수와 합 구하기
- 2차원 배열의 for-each : 바깥은 `int[] row`, 안쪽은 `int num`

```java
public class Array07 {
    public static void main(String[] args) {
        int[][] grid = {
            {2, 3, 1, 4, 7},
            {8, 13, 3, 33, 1},
            {7, 4, 5, 80, 12},
            {17, 9, 11, 5, 4},
            {4, 5, 91, 27, 7}
        };
        int count = 0;
        int sum = 0;
        for (int[] row : grid) {          // 행 하나 = int[]
            for (int num : row) {
                if (num % 3 == 0) {
                    count++;
                    sum += num;
                }
            }
        }
        System.out.printf("개수: %d, 총합: %d%n", count, sum);  // 개수: 6, 총합: 87
    }
}
```

### 기본 문제 — X의 좌우 숫자 합 (Array_08)

- 4x4 배열에서 X로 표시된 칸의 **좌우** 숫자의 합
- 왼쪽 `c - 1 >= 0`, 오른쪽 `c + 1 < 4` 로 범위 검사 + 이웃이 X가 아닐 때만 더함
- 문자 숫자 → 정수 : `- '0'`

```text
  2 3 1 4
  1 X 3 2
  3 4 X X
  X 4 1 5
```

```java
public class Array08 {
    public static void main(String[] args) {
        char[][] grid = {
            {'2', '3', '1', '4'},
            {'1', 'X', '3', '2'},
            {'3', '4', 'X', 'X'},
            {'X', '4', '1', '5'}
        };
        int sum = 0;
        for (int r = 0; r < 4; r++) {
            for (int c = 0; c < 4; c++) {
                if (grid[r][c] == 'X') {
                    // 왼쪽 살펴보기
                    if (c - 1 >= 0 && grid[r][c - 1] != 'X')
                        sum += grid[r][c - 1] - '0';
                    // 오른쪽 살펴보기
                    if (c + 1 < 4 && grid[r][c + 1] != 'X')
                        sum += grid[r][c + 1] - '0';
                }
            }
        }
        System.out.println(sum);  // 12  (1+3) + (4) + (4)
    }
}
```

### 기본 문제 — X의 상하좌우 숫자 합, 중복 제외 (Array_09)

- X 칸의 **상하좌우** 숫자 합
- 행·열 오름차순으로 접근, **상 > 하 > 좌 > 우** 순서로 탐색
- **이미 사용된 숫자는 다시 사용하지 않음** (예: (2,1)의 4는 위의 X와 오른쪽 X 모두에 인접하지만 한 번만 더함) → 더한 칸을 `'0'` 으로 바꿔 다시 더해도 0이 되게 함
- 방향을 **델타 배열**로 관리하면 4방향 코드를 반복문 하나로 처리

| d | 방향 | dr | dc |
| --- | --- | --- | --- |
| 0 | 상 | -1 | 0 |
| 1 | 하 | 1 | 0 |
| 2 | 좌 | 0 | -1 |
| 3 | 우 | 0 | 1 |

```java
public class Array09 {
    public static void main(String[] args) {
        char[][] grid = {
            {'2', '3', '1', '4'},
            {'1', 'X', '3', '2'},
            {'3', '4', 'X', 'X'},
            {'X', '4', '1', '5'}
        };
        int[][] deltas = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};  // 상, 하, 좌, 우
        int sum = 0;
        for (int r = 0; r < 4; r++) {
            for (int c = 0; c < 4; c++) {
                if (grid[r][c] == 'X') {
                    for (int d = 0; d < 4; d++) {
                        int nr = r + deltas[d][0];
                        int nc = c + deltas[d][1];
                        if (nr >= 0 && nr < 4 && nc >= 0 && nc < 4 && grid[nr][nc] != 'X') {
                            sum += grid[nr][nc] - '0';
                            grid[nr][nc] = '0';   // 사용한 숫자는 0으로 → 다시 더해도 영향 없음
                        }
                    }
                }
            }
        }
        System.out.println(sum);  // 26
    }
}
```

## 참고

- 2차원 배열 내용 출력은 `Arrays.toString()` 이 아니라 **`Arrays.deepToString()`** (`toString` 은 안쪽 배열의 주소 문자열이 찍힘)
- Array_08·09의 격자는 교재 그림의 숫자 배치를 옮긴 것이고, 답(12, 26)은 위 코드 실행 결과다(교재에는 답이 없다)
