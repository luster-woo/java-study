## 학습 목표

- 제어문(조건문, 반복문)을 사용하여 프로그램의 흐름을 설계·구현할 수 있다

---

## 제어문(Control Statements)

- 프로그램의 **흐름을 제어**하기 위한 문법 구조
- 코드의 논리적 흐름 관리와 반복 작업의 효율성을 위해 필요

| 종류 | 역할 |
| --- | --- |
| **조건문** (Conditional Statements) | 특정 조건에 따라 코드 실행 여부 결정 |
| **반복문** (Loops) | 특정 조건이 참일 때 코드 블록 반복 실행 |
| **분기문** (Branching Statements) | 반복문·조건문 내에서 코드 흐름 변경 |

## 조건문

### if 문

- 조건식 결과에 따라 코드 블록 실행
- **조건식** : `true`/`false` 를 산출하는 연산식 또는 `boolean` 변수
- 참이면 블록 실행, 거짓이면 실행하지 않음
- 실행할 문장이 하나면 중괄호 생략 가능

```java
if (조건식) {
    // 조건식이 참(true)일 때 실행될 코드 블록
}
```

### if - else 문

- 참이면 `if` 블록, 거짓이면 `else` 블록 실행

```java
int score = 85;
if (score >= 60) {
    System.out.println("통과");           // 통과
}
if (score >= 90) System.out.println("A"); // 중괄호 생략 (문장 하나)
else System.out.println("A 아님");        // A 아님
```

### 중첩 if 문

- 조건문 안에 조건문 — 중첩 횟수 제한 없음

```java
boolean member = true;
if (score >= 80) {                 // 조건식 A
    if (member) {                  // 조건식 B
        System.out.println("우수 회원");     // A, B 모두 참 → 출력: 우수 회원
    } else {
        System.out.println("우수 비회원");   // A 참, B 거짓
    }
} else {
    System.out.println("일반");             // A 거짓
}
```

### if - else if - else 문

- `else if` 블록은 여러 개 올 수 있음
- 조건식이 거짓이면 다음 조건식을 확인
- 참인 조건을 만나면 그 블록만 실행하고 **끝** — 그 다음 조건식은 검사하지 않음

```java
if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");   // B (여기서 끝, 아래는 검사 안 함)
} else if (score >= 70) {
    System.out.println("C");
} else {
    System.out.println("F");   // 모든 조건식이 거짓일 때
}
```

### if - else if / if - if

- `else if` : 서로 **연관된** 조건일 때
- 관련 없는 **독립** 조건이면 `if` 를 따로 사용

```java
int n = 12;
// 연관된 조건 → 하나만 실행
if (n % 2 == 0) System.out.println("짝수");        // 짝수
else if (n % 3 == 0) System.out.println("3의 배수"); // (검사 안 함)

// 독립 조건 → 각각 검사
if (n % 2 == 0) System.out.println("짝수");        // 짝수
if (n % 3 == 0) System.out.println("3의 배수");    // 3의 배수
```

### switch 문

- 선택 변수의 **값**에 따라 실행 블록 결정
- 값이 일치하는 `case` 부터 시작해 `break` 를 만나면 종료
- 일치하는 값이 없으면 `default` 에서 시작
- 변수 자리에 올 수 있는 값

| 타입 | 비고 |
| --- | --- |
| `byte`, `short`, `char`, `int` | |
| `String` | Java 7 이상 |
| `enum` | Java 5 이상 |
| Wrapper Class | `Byte`, `Short`, `Character`, `Integer` |

```java
int grade = 2;
switch (grade) {
    case 1:
        System.out.println("1등급");
        break;
    case 2:
        System.out.println("2등급");   // 2등급
        break;
    default:
        System.out.println("등급 없음");
}

String cmd = "stop";
switch (cmd) {                          // String 사용
    case "go":
        System.out.println("출발");
        break;
    case "stop":
        System.out.println("정지");     // 정지
        break;
    default:
        System.out.println("알 수 없음");
}

int k = 1;
switch (k) {                            // break가 없으면 아래 case로 이어서 실행
    case 1:
        System.out.println("one");      // one
    case 2:
        System.out.println("two");      // two
        break;
    case 3:
        System.out.println("three");
}
```

### switch expressions (Java 14 ~)

- switch를 **표현식**으로 써서 값을 반환 (`break` 불필요)
- `case 값 ->` 형태, 동일한 처리를 하는 case는 쉼표로 묶음
- 블록이 필요하면 **`yield`** 로 값 반환

```java
int grade = 2;
String result = switch (grade) {
    case 1 -> "1등급";
    case 2 -> "2등급";
    case 3 -> "3등급";
    default -> "등급 없음";
};
System.out.println(result);  // 2등급

int num = 4;
String size = switch (num) {
    case 1, 2, 3 -> "작은 수";
    case 4, 5, 6 -> "중간 수";
    default -> "큰 수";
};
System.out.println(size);    // 중간 수

String label = switch (num) {
    case 4 -> {                 // 여러 줄 블록일 때
        String t = "넷";
        yield t + "(4)";        // yield로 값 반환
    }
    default -> "기타";
};
System.out.println(label);   // 넷(4)
```

## 반복문(Loops)

### for 문

```java
for (① 초기화; ② 조건식; ④ 증감식) {
    // ③ 반복할 코드 블록
}
// 실행 순서: ① → ② → ③ → ④ → ② → ③ → ④ → ... → ②가 false면 종료
```

- **초기화**는 반복문이 시작될 때 딱 한 번 실행
- **조건식**이 false이면 반복문 종료
- **증감식**은 한 번의 반복이 끝나면 실행
- 초기화식·증감식은 `,` 로 둘 이상 작성 가능
- 필요 없는 부분은 생략 가능 — `for ( ; ; )` 는 무한 루프
- **반복 횟수를 알고 있을 때** 유용, 중첩 가능

```java
for (int i = 0; i < 3; i++) {
    System.out.print(i + " ");
}
// 0 1 2

for (int i = 0, j = 10; i < j; i += 3, j -= 3) {   // 쉼표로 둘 이상
    System.out.print(i + ":" + j + " ");
}
// 0:10 3:7

for (int i = 2; i <= 3; i++) {                     // 중첩 for
    for (int j = 1; j <= 3; j++) {
        System.out.print(i + "x" + j + "=" + (i * j) + " ");
    }
    System.out.println();
}
/* 출력
2x1=2 2x2=4 2x3=6
3x1=3 3x2=6 3x3=9
*/
```

### while 문

```java
while (조건식) {
    // 반복할 코드 블록
}
```

- 조건식이 **true인 동안** 계속 반복 (거짓이 될 때까지)
- 조건식 생략 불가
- **반복 횟수를 명확히 알 수 없을 때** 사용

```java
int n = 1;
while (n < 100) {
    n *= 2;
}
System.out.println(n);  // 128
```

### do-while 문

```java
do {
    // 반복할 코드 블록
} while (조건식);   // 세미콜론 주의
```

- 블록을 **먼저 수행한 뒤** 조건식 판단 → **최소 한 번은 수행**
- 조건식이 true인 동안 반복, 조건식 생략 불가

```java
int m = 100;
do {
    System.out.println("do 블록 실행: " + m);  // do 블록 실행: 100
} while (m < 10);                              // 조건이 처음부터 거짓이어도 1번 실행
```

## 분기문(Branching Statements)

### break 문

- `switch`, `while`, `do-while`, `for` 블록에서 **빠져나올 때** 사용
- **가장 가까운** 반복문을 빠져나감
- 중첩 반복문에서 반복문에 **이름(라벨)** 을 붙여 한 번에 빠져나올 수 있음

### continue 문

- 현재 반복의 **나머지 부분을 건너뛰고 다음 반복**으로 감
- 중첩 반복문에서 라벨을 붙여 특정 반복을 건너뛸 수 있음

```java
for (int i = 1; i <= 10; i++) {
    if (i == 4) break;           // 4에서 반복 종료
    System.out.print(i + " ");
}
// 1 2 3

for (int i = 1; i <= 5; i++) {
    if (i % 2 == 0) continue;    // 짝수는 건너뜀
    System.out.print(i + " ");
}
// 1 3 5

outer:                           // 바깥 반복문에 라벨
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) continue outer;  // 안쪽 나머지를 건너뛰고 바깥 반복의 다음 i로
        if (i == 3) break outer;     // 바깥 반복문까지 한 번에 종료
        System.out.print(i + "," + j + " ");
    }
}
// 1,1 2,1
```
