## 변수(Variable)

### 정의

- 컴퓨터 메모리의 **데이터 저장소**
- 데이터에 **이름**을 부여하여 관리
- 자료형에 따라 **값** 또는 **참조 값**을 저장
- `=` 를 통해 CPU에게 연산 작업(대입)을 의뢰

### 변수 작명 규칙

- 대/소문자 구분, 공백 불가
- **숫자로 시작할 수 없음**
- 특수문자는 `$`, `_` 만 사용 가능
- 자바 **예약어(키워드)** 사용 불가 — `public`, `private`, `import`, `for`, `if` ... (IDE에서 색이 변하는 것들)
- 의미를 담아서 지을 것 (관례)
- 합성어는 주로 **camelCase** 표기법 사용 (예: `studentName`, `maxScore`)

## 자료형(Data Type)

- **기본 자료형(Primitive Type)** : 변수 자체에 값(**리터럴, literal**)이 직접 저장됨 — 8가지
- **참조 자료형(Reference Type)** : 기본 자료형 8가지 외 모든 것, 변수에 **참조(주소)** 를 저장, 기본값은 `null`(아무것도 참조하지 않음)

| 타입 | 세부 타입 | 데이터형 | 크기 | 기본값 | 값의 범위 |
| --- | --- | --- | --- | --- | --- |
| 논리형 | - | `boolean` | - | `false` | `true` / `false` |
| 숫자형 | 문자형 | `char` | 2byte | 널문자(`\u0000`) | 0 ~ 65,535 |
| 숫자형 | 정수형 | `byte` | 1byte | `(byte)0` | -128 ~ 127 |
| 숫자형 | 정수형 | `short` | 2byte | `(short)0` | -32,768 ~ 32,767 |
| 숫자형 | 정수형 | `int` | 4byte | `0` | -2,147,483,648 ~ 2,147,483,647 |
| 숫자형 | 정수형 | `long` | 8byte | `0L` | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 |
| 숫자형 | 실수형 | `float` | 4byte | `0.0f` | -3.4028235e38 ~ 3.4028235e38 |
| 숫자형 | 실수형 | `double` | 8byte | `0.0d` | -1.7976931348623157e308 ~ 1.7976931348623157e308 |

### 변수의 선언과 초기화

- **선언** : 데이터를 저장할 공간을 확보하고 이름을 부여하는 작업 — `자료형 이름;`
- **초기화** : 변수에 값을 저장하는 과정
- 선언과 동시에 초기화 가능

```java
public class VarDemo {
    public static void main(String[] args) {
        int a;          // 선언
        int b;
        double c, d;    // 같은 타입 여러 개 선언

        a = 10;         // 초기화
        b = 100;
        int f = 1000;   // 선언과 동시에 초기화

        System.out.println(a + " " + b + " " + f);   // 10 100 1000

        long big = 10_000_000_000L;  // int 범위를 넘는 정수는 L
        float pi = 3.14f;            // float 리터럴은 f
        char ch = 'A';
        boolean ok = true;
        System.out.println(big + " " + pi + " " + ch + " " + ok);  // 10000000000 3.14 A true

        System.out.println(Integer.MAX_VALUE);          // 2147483647
        System.out.println(Long.MAX_VALUE);             // 9223372036854775807
        System.out.println((int) Character.MAX_VALUE);  // 65535
    }
}
```

```text
int a      int b      double c    double d    int f
[ 10 ]     [ 100 ]    [  ?  ]     [  ?  ]     [ 1000 ]
```

> 참고: 교재 그림은 선언만 한 칸에 `0`, `0.0` 이 들어간 것으로 그렸지만, 위처럼 **지역 변수**는 자동 초기화되지 않는다(아래 "변수의 종류"). 초기화 전 읽으면 컴파일 오류.

### 변수의 종류

| 종류 | 선언 위치 | 특징 |
| --- | --- | --- |
| **지역 변수** (Local Variable) | 메서드나 블록 내부 | 해당 범위 내에서만 유효, **초기화하지 않으면 사용 불가** |
| **멤버 변수** (Instance Variable) | 클래스 내부 | 객체가 생성될 때 메모리에 할당, 초기화하지 않으면 자료형의 **기본값**으로 자동 초기화 |
| **클래스 변수** (Static Variable) | 클래스 내부, `static` | 모든 객체가 공유, 클래스 로드 시 메모리에 한 번만 생성 |

- 멤버 변수·클래스 변수는 이후 학습 내용

```java
int count;
// System.out.println(count);  // 컴파일 오류: variable count might not have been initialized
```

## 형 변환(Type Casting)

| 구분 | 방향 | 데이터 손실 | 방법 |
| --- | --- | --- | --- |
| **묵시적 형 변환** (Implicit) | 작은 타입 → 큰 타입 | 없음 | **자동** 변환 |
| **명시적 형 변환** (Explicit) | 큰 타입 → 작은 타입 | 가능성 있음 | `(타입)` 으로 **직접 명시** |

- 작은/큰 데이터 타입 = 메모리 할당 크기가 아니라 그 자료형이 **표현할 수 있는 수의 범위**

```java
int x = 10;
double y = x;          // int → double (자동 변환)
double z = 9.99;
int w = (int) z;       // double → int (명시적 변환, 소수점 버림)
System.out.println(y + " " + w);  // 10.0 9

long l = 100;
float ff = l;          // long(8byte) → float(4byte)도 자동: float의 표현 범위가 더 넓음
System.out.println(ff);           // 100.0
```

## 참고

- 정수 범위를 넘는 리터럴은 `L`, `float` 리터럴은 `f` 접미사가 필요 (`long big = 10_000_000_000L;`, `float pi = 3.14f;`)
