## 출력 예측

### 출력 1

```java
int a = 7, b = 2;
double c = a / b;
System.out.println(c);
System.out.println(a / (double) b);
System.out.println(a % b + a / b);
```

**답**

```
3.0
3.5
4
```

- `a / b`는 정수끼리 나눠서 먼저 `3`이 나온다. 그 값이 double 변수에 들어가서 `3.0`이 된다. 실수로 바뀌는 건 나눗셈이 **끝난 뒤**다.
- `a / (double) b`는 한쪽이 실수라 실수 나눗셈이다. 결과는 `3.5`.
- `%`와 `/`가 `+`보다 먼저 계산된다. `1 + 3 = 4`.

### 출력 2

```java
int i = 3;
int j = i++ + ++i;
System.out.println(i + " " + j);
```

**답**

```
5 8
```

- `i++`(후치)는 현재 값 **3을 먼저 쓰고**, 그다음 i를 4로 올린다.
- `++i`(전치)는 i를 **먼저 5로 올리고** 5를 쓴다.
- j = 3 + 5 = 8, i = 5

### 출력 3

```java
String s = "Java";
System.out.println(s + 1 + 2);
System.out.println(1 + 2 + s);
System.out.println('A' + 1);
System.out.println("" + 'A' + 1);
```

**답**

```
Java12
3Java
66
A1
```

`+`는 **왼쪽부터** 계산한다.

- `"Java" + 1` → `"Java1"`, `+ 2` → `"Java12"`. 문자열이 한 번 나오면 그 뒤는 전부 이어붙이기다.
- `1 + 2`는 숫자끼리라 먼저 `3`이 되고, 그다음 `"3Java"`가 된다.
- `'A' + 1`에서 char는 숫자(A = 65)로 계산된다. 결과는 `66`.
- `"" + 'A'`가 먼저 문자열 `"A"`가 되고, `1`을 이어붙여 `"A1"`이다.

### 출력 4

```java
int x = 2;
switch (x) {
    case 1: System.out.print("one ");
    case 2: System.out.print("two ");
    case 3: System.out.print("three ");
        break;
    default: System.out.print("other ");
}
```

**답**

```
two three 
```

- x = 2라서 `case 2`부터 실행된다.
- `case 2`에 `break`가 없어서 `case 3`까지 그대로 내려간다. 이걸 **fall-through**라고 한다.
- `case 3`의 `break`에서 멈춘다. 출력 끝에 공백 하나가 남는다.
- `case 2 -> ...` 화살표 문법(switch expressions)을 쓰면 이런 실수가 생기지 않는다.

## 버그 찾기

### 버그 1 · 평균 구하기

```java
int[] arr = {1, 2, 3, 4};
int sum = 0;
for (int i = 0; i <= arr.length; i++) {
    sum += arr[i];
}
System.out.println("평균: " + sum / arr.length);
```

**문제점 2개**

1. `i <= arr.length` → 마지막에 `arr[4]`에 접근해서 `ArrayIndexOutOfBoundsException`이 난다. 인덱스는 0부터 `length - 1`까지다.
   **수정:** `i < arr.length`
2. `sum / arr.length`는 정수 나눗셈이라 `10 / 4 = 2`가 나온다.
   **수정:** `(double) sum / arr.length` → `2.5`

### 버그 2 · 입력 비교

```java
Scanner sc = new Scanner(System.in);
String answer = sc.next();
if (answer == "yes") {
    System.out.println("확인");
}
```

**문제점**

- `==`는 **같은 객체(주소)인지**를 비교한다. 내용이 같은지는 보지 않는다.
- `sc.next()`로 받은 문자열은 새로 만들어진 객체다. 그래서 `yes`를 입력해도 false가 나온다.

**수정:** `answer.equals("yes")`
→ `"yes".equals(answer)`로 쓰면 answer가 null이어도 `NullPointerException`이 나지 않는다.

## 빈칸 채우기

### 빈칸 1 · 배열 뒤집기 (새 배열 없이)

```java
int[] a = {1, 2, 3, 4, 5};
for (int i = 0; i < a.length / 2; i++) {
    int tmp = a[i];
    a[i] = a[a.length - 1 - i];
    a[a.length - 1 - i] = tmp;
}
// a = [5, 4, 3, 2, 1]
```

- 앞의 i번째와 뒤의 i번째(`length - 1 - i`)를 서로 바꾼다.
- 반복은 **절반까지만** 한다. 끝까지 돌면 한 번 바꾼 걸 다시 바꿔서 원래대로 돌아온다.

### 빈칸 2 · 행렬 전치

```java
int[][] m = {{1, 2, 3}, {4, 5, 6}};          // 2행 3열
int[][] t = new int[m[0].length][m.length];  // 3행 2열
for (int i = 0; i < m.length; i++) {
    for (int j = 0; j < m[i].length; j++) {
        t[j][i] = m[i][j];
    }
}
```

- 원래 열 수 `m[0].length`가 새 행렬의 행 수, 원래 행 수 `m.length`가 새 행렬의 열 수가 된다.
- (i, j) 위치의 값이 (j, i) 위치로 간다.

## 핵심 정리

| 함정 | 기억할 것 |
|---|---|
| 정수 나눗셈 | `int / int`는 소수점이 버려진다. 한쪽을 `(double)`로 바꿔야 실수 나눗셈 |
| 전치/후치 증감 | `i++`는 쓰고 증가, `++i`는 증가하고 씀 |
| 문자열 `+` | 왼쪽부터 계산. 문자열이 나온 뒤로는 전부 이어붙이기 |
| char 연산 | `'A' + 1` = 66 (char는 숫자로 계산) |
| switch | `break` 없으면 아래 case로 내려감 (fall-through) |
| 배열 범위 | 인덱스는 `0 ~ length-1`, 조건은 `i < length` |
| 문자열 비교 | `==` 말고 `equals()` |
