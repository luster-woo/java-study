### InputStreamReader & OutputStreamWriter

- **byte 기반 스트림을 char 기반으로** 바꿔 주는 스트림
    - 문자열을 다룰 때는 byte 단위보다 char 단위가 유리
    - 키보드 입력(byte stream)을 문자로 처리할 때 등
- 변환할 때 **encoding 지정 가능**

| 생성자 | 설명 |
| --- | --- |
| `InputStreamReader(InputStream in)` | 기본 캐릭터 셋 사용 |
| `InputStreamReader(InputStream in, String charsetName)` | charsetName 사용 (`throws UnsupportedEncodingException`) |
| `InputStreamReader(InputStream in, Charset cs)` | cs 사용 |
| `OutputStreamWriter(OutputStream out)` | 기본 캐릭터 셋 사용 |
| `OutputStreamWriter(OutputStream out, String charsetName)` | charsetName 사용 (`throws UnsupportedEncodingException`) |
| `OutputStreamWriter(OutputStream out, Charset cs)` | cs 사용 |

```java
import java.io.*;
import java.nio.charset.StandardCharsets;

public class ConvertTest {
    public static void main(String[] args) throws IOException {
        byte[] bytes = "자바 스트림".getBytes(StandardCharsets.UTF_8);
        // byte → char (인코딩 지정)
        try (Reader reader = new InputStreamReader(new ByteArrayInputStream(bytes), "UTF-8")) {
            int c;
            while ((c = reader.read()) != -1) {
                System.out.print((char) c + "|");
            }
            System.out.println();                       // 자|바| |스|트|림|
        }
        // char → byte
        ByteArrayOutputStream bout = new ByteArrayOutputStream();
        try (Writer writer = new OutputStreamWriter(bout, StandardCharsets.UTF_8)) {
            writer.write("가나");
        }
        System.out.println(bout.size());                 // 6 (한글 2자 x 3byte)
    }
}
```

- 키보드에서 줄 단위로 읽는 전형적인 체이닝

```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
String line = br.readLine();
```

### Buffered 계열

- **버퍼(buffer)** 의 역할: 전송과 처리를 따로 하게 해 성능 문제 해결
    - 예: 네트워크로 받는 영상을 버퍼에 모아 두고 플레이어는 버퍼에서 꺼내 재생
- 스트림의 입출력 효율을 높이기 위해 버퍼를 사용하는 스트림

| 생성자 | 설명 |
| --- | --- |
| `BufferedInputStream(InputStream in)` | 크기 **8192** 버퍼 |
| `BufferedInputStream(InputStream in, int size)` | 크기 size 버퍼 |
| `BufferedOutputStream(OutputStream out)` | 크기 8192 버퍼 |
| `BufferedOutputStream(OutputStream out, int size)` | 크기 size 버퍼 |

```java
import java.io.*;

public class BufferedCopy {
    public static void main(String[] args) throws IOException {
        File src = new File("big2.bin");
        try (FileOutputStream out = new FileOutputStream(src)) {
            out.write(new byte[20 * 1024 * 1024]);       // 20MB 테스트 파일
        }
        File target = new File("big2_copy.bin");
        try (FileInputStream fi = new FileInputStream(src);
             FileOutputStream fo = new FileOutputStream(target)) {
            copy("노드", fi, fo);
        }
        try (BufferedInputStream bi = new BufferedInputStream(new FileInputStream(src));
             BufferedOutputStream bo = new BufferedOutputStream(new FileOutputStream(target))) {
            copy("보조", bi, bo);
        }
    }
    static void copy(String type, InputStream input, OutputStream output) throws IOException {
        long start = System.nanoTime();
        byte[] cart = new byte[1024];
        int read;
        while ((read = input.read(cart)) > 0) {
            output.write(cart, 0, read);
        }
        System.out.println(type + ", 소요 시간: " + (System.nanoTime() - start) + "ns");
    }
}
/* 출력 예 (시간은 실행마다 다름)
노드, 소요 시간: 41507467ns
보조, 소요 시간: 24819750ns
*/
```

- `copy()` 는 `InputStream`/`OutputStream` 타입으로 받으므로 노드·보조 스트림 모두 전달 가능 (다형성)

### BufferedReader & BufferedWriter

| 생성자 | 설명 |
| --- | --- |
| `BufferedReader(Reader in)` | 크기 8192 버퍼 |
| `BufferedReader(Reader in, int sz)` | 크기 sz 버퍼 |
| `BufferedWriter(Writer out)` | 크기 8192 버퍼 |
| `BufferedWriter(Writer out, int sz)` | 크기 sz 버퍼 |

- `BufferedReader.readLine()`: **줄 단위**로 읽음, 끝이면 null

```java
import java.io.*;

public class ReadLineTest {
    public static void main(String[] args) throws IOException {
        File src = new File("lines.txt");
        try (BufferedWriter bw = new BufferedWriter(new FileWriter(src))) {
            bw.write("첫째 줄");
            bw.newLine();                               // 줄바꿈
            bw.write("둘째 줄");
        }
        try (BufferedReader br = new BufferedReader(new FileReader(src))) {
            String line;
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
        }
    }
}
/* 출력
첫째 줄
둘째 줄
*/
```

### 객체 직렬화(serialization)

- **직렬화**: 객체를 파일에 저장하거나 네트워크로 전송하려고 **연속적인 데이터로 변환**하는 것
- **역직렬화(deserialization)**: 그 반대

```
스택: Person p (0x100) ─→ 힙: { name, age }
                              │ 직렬화(output)          ↑ 역직렬화(input)
                              ↓                         │
                         파일: name: .. age: .. ────────┘
```

- 직렬화 조건
    - **Serializable** 인터페이스를 구현할 것 (필수)
    - 클래스의 **모든 멤버**도 Serializable 을 구현해야 함 (has-a 관계 객체 포함)
    - 직렬화에서 제외하려는 멤버는 **transient** 선언
    - **static 변수도 직렬화에서 제외** (객체 직렬화이므로)

```java
class Person implements Serializable {   // 직렬화 필수 조건
    private String name;
    private int age;
    private transient String ssn;        // 직렬화 제외
    private LoginInfo lInfo;             // LoginInfo 도 Serializable 이어야 함
}
```

### serialVersionUID

- 클래스의 변경 여부를 파악하기 위한 **유일 키**
- 직렬화할 때의 UID 와 역직렬화할 때의 UID 가 다르면 예외 발생

```
class Person (001 버전) ──직렬화──→ 파일(001)
   구조 변경
class Person (002 버전) ←─역직렬화── 파일(001)   → 예외 발생 (InvalidClassException)
```

- UID 를 직접 설정하지 않으면 컴파일러가 자동 생성 → 멤버가 바뀌어 다시 컴파일할 때마다 값이 바뀜 → `InvalidClassException`
- 직렬화 대상 클래스에는 **serialVersionUID 를 직접 설정**하는 것을 권장

```java
private static final long serialVersionUID = 1L;
```

### ObjectInputStream, ObjectOutputStream

| 메서드 | 설명 |
| --- | --- |
| `ObjectOutputStream(OutputStream out)` | 생성 (`throws IOException`) |
| `final void writeObject(Object obj)` | obj 를 직렬화해 출력 (`throws IOException`) |
| `ObjectInputStream(InputStream in)` | 생성 (`throws IOException`) |
| `final Object readObject()` | 역직렬화해 Object 로 반환 (`throws IOException, ClassNotFoundException`) |

```java
import java.io.*;

public class SerialTest {
    private static File target = new File("objPerson.dat");

    public static void main(String[] args) {
        write();
        read();
    }
    private static void write() {
        Person person = new Person("홍길동", "pass1234", "123-456", "seoul");
        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream(target))) {
            oos.writeObject(person);                     // 직렬화
            System.out.println("저장 완료");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    private static void read() {
        try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream(target))) {
            Object readed = ois.readObject();            // 역직렬화
            if (readed instanceof Person) {
                Person casted = (Person) readed;
                System.out.println("로딩 완료: " + casted);
            }
        } catch (IOException | ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}

class Person implements Serializable {
    private static final long serialVersionUID = 1L;
    private String id;
    private transient String pass;                     // 민감한 데이터 — 직렬화 제외
    private Address addr;                              // has-a 관계의 다른 객체

    public Person(String id, String pass, String zipCode, String city) {
        this.id = id;
        this.pass = pass;
        this.addr = new Address(zipCode, city);
    }
    @Override
    public String toString() {
        return "[id=" + id + ", pass=" + pass + ", addr=" + addr + "]";
    }
}

class Address implements Serializable {
    private static final long serialVersionUID = 1L;
    private String zipCode;
    private String city;

    public Address(String zipCode, String city) {
        this.zipCode = zipCode;
        this.city = city;
    }
    @Override
    public String toString() {
        return "Address [zipCode=" + zipCode + ", city=" + city + "]";
    }
}
/* 출력
저장 완료
로딩 완료: [id=홍길동, pass=null, addr=Address [zipCode=123-456, city=seoul]]
*/
```

- transient 인 `pass` 는 저장되지 않아 복원하면 `null`
- 멤버 객체가 Serializable 이 아니면 `NotSerializableException: 클래스명` 발생

> 참고: 교재는 `if (readed instanceof Person casted)` (패턴 매칭 instanceof, Java 16+)로 검사와 형변환을 한 줄에 쓴다. 위 코드는 같은 뜻의 옛 형태.

> 교재 과제: Person 에 별명 필드를 추가해 보기 (앞의 serialVersionUID 설명과 연결).

### Scanner와 BufferedReader

- 둘 다 char 형태 데이터를 읽기 위한 클래스

| | Scanner | BufferedReader |
| --- | --- | --- |
| 장점 | 자동 형변환 지원 등 사용이 간편 | 속도가 빠름 |
| 단점 | 속도가 느림 | 스트림을 직접 구성해야 하는 등 번거로움 |

```java
import java.io.*;
import java.util.Scanner;

public class SpeedTest {
    static File file = new File("speed.txt");

    public static void main(String[] args) throws IOException {
        try (BufferedWriter bw = new BufferedWriter(new FileWriter(file))) {
            for (int i = 0; i < 100_000; i++) {
                bw.write("line " + i);
                bw.newLine();
            }
        }
        useBufferedReader();
        useScanner();
    }
    static void useScanner() throws FileNotFoundException {
        try (Scanner s = new Scanner(file)) {
            long start = System.nanoTime();
            while (s.hasNextLine()) {
                s.nextLine();
            }
            System.out.printf("sc: %10d%n", System.nanoTime() - start);
        }
    }
    static void useBufferedReader() throws IOException {
        try (BufferedReader br = new BufferedReader(new FileReader(file))) {
            long start = System.nanoTime();
            while (br.readLine() != null) { }
            System.out.printf("br: %10d%n", System.nanoTime() - start);
        }
    }
}
/* 출력 예 (ns, 실행마다 다름)
br:   19419928
sc:  150478592
*/
```
