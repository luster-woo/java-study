### 사용자 정의 예외

- API에 정의된 예외 외에 필요에 따라 직접 예외 클래스 작성
- 대부분 `Exception` 또는 `RuntimeException` 을 상속

| 상속 대상 | 특징 | 장단점 |
| --- | --- | --- |
| `Exception` (checked) | 명시적 예외 처리 또는 throws 필요 | 코드는 복잡해지지만 처리 누락 가능성 줄어듦 |
| `RuntimeException` (unchecked) | 묵시적 예외 처리 가능 | 코드는 간결하지만 처리 누락 가능성 있음 |

- 사용자 정의 예외의 장점
    - **객체의 활용** — 필요한 추가 정보·기능 활용 가능
    - **코드의 재사용** — 같은 상황에서 예외 객체 재사용
    - **throws 메커니즘 이용** — 중간 호출 단계에서 return 값 확인 불필요

### 예외 없이 작성한 경우 — boolean 리턴

```java
public class UserExceptionTest {
    private static String[] fruits = { "사과", "오렌지", "토마토" };

    public static void main(String[] args) {
        boolean result = getFruit1("사과");
        if (!result) System.out.println("사과는 없습니다.");
        result = getFruit1("사과");
        if (!result) System.out.println("사과는 없습니다.");
        System.out.println("창고 관리 끝~");
    }
    private static boolean getFruit1(String name) {
        for (int i = 0; i < fruits.length; i++) {
            if (fruits[i] != null && fruits[i].equals(name)) {
                fruits[i] = null;
                return true;
            }
        }
        return false;
    }
}
/* 출력
사과는 없습니다.
창고 관리 끝~
*/
```

- 호출할 때마다 리턴값을 확인해야 함 → "과일이 없는 상태"를 예외로 만들기

### 사용자 정의 예외 작성

```java
public class CustomExceptionTest {
    private static String[] fruits = { "사과", "오렌지", "토마토" };

    public static void main(String[] args) {
        try {
            getFruit2("오렌지");
            System.out.println("오렌지 꺼냄");
            getFruit2("오렌지");
            System.out.println("여기는 실행되지 않음");
        } catch (FruitNotFoundException e) {
            System.out.println(e.getMessage());
        }
        // 교재 과제: 배열 빈 칸에 과일을 넣는데 넣을 곳이 없으면 예외
        try {
            addFruit("포도");      // 오렌지가 빠진 칸(null)에 들어감
            addFruit("수박");      // 빈 칸 없음
        } catch (NoSpaceException e) {
            System.out.println(e.getMessage());
        }
        System.out.println(java.util.Arrays.toString(fruits));
    }
    private static void getFruit2(String name) throws FruitNotFoundException {
        for (int i = 0; i < fruits.length; i++) {
            if (fruits[i] != null && fruits[i].equals(name)) {
                fruits[i] = null;
                return;
            }
        }
        throw new FruitNotFoundException(name);
    }
    private static void addFruit(String name) throws NoSpaceException {
        for (int i = 0; i < fruits.length; i++) {
            if (fruits[i] == null) {
                fruits[i] = name;
                return;
            }
        }
        throw new NoSpaceException(name);
    }
}
class FruitNotFoundException extends Exception {
    public FruitNotFoundException(String name) {
        super(name + "에 해당하는 과일은 없습니다.");
    }
}
class NoSpaceException extends Exception {
    public NoSpaceException(String name) {
        super(name + "을(를) 넣을 빈 칸이 없습니다.");
    }
}
/* 출력
오렌지 꺼냄
오렌지에 해당하는 과일은 없습니다.
수박을(를) 넣을 빈 칸이 없습니다.
[사과, 포도, 토마토]
*/
```

- 생성자에서 `super(메시지)` 로 메시지를 정해 두면 `getMessage()` 로 꺼냄
- 교재는 catch 에서 `e.printStackTrace()` 로 출력
