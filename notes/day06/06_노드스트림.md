### I/O와 Stream

- **I/O**: 데이터의 입력(input)과 출력(output)
- 데이터는 한쪽에서 주고 한쪽에서 받는 구조
    - 입력과 출력의 끝단: **노드(Node)**
    - 두 노드를 연결해 데이터를 전송하는 개념: **스트림(Stream)** — 물·전기의 흐름과 같은 개념
- 스트림은 **단방향** → 하나의 스트림으로 입력과 출력을 같이 처리할 수 없음

```
노드(키보드·파일·메모리·DB·네트워크 ...)
   ──입력 스트림(InputStream, Reader)──→  Program  ──출력 스트림(OutputStream, Writer)──→  노드(콘솔·파일 ...)
```

### Node Stream의 종류와 naming

- **노드 스트림**: 노드에 직접 연결되는 스트림
- 이름 규칙: 데이터 타입(byte/char) × 방향(입력/출력)

| 데이터 타입 | 입력 | 출력 |
| --- | --- | --- |
| byte | `XXInputStream` | `XXOutputStream` |
| char | `XXReader` | `XXWriter` |

- 노드 타입에 따른 최종 노드 스트림

| 노드 | byte 기반 | char 기반 |
| --- | --- | --- |
| 키보드 / 콘솔 | `InputStream` / `OutputStream` | `Reader` / `Writer` |
| File | `FileInputStream`, `FileOutputStream` | `FileReader`, `FileWriter` |
| 메모리(배열) | `ByteArrayInputStream`, `ByteArrayOutputStream` | `CharArrayReader`, `CharArrayWriter` |
| String | — | `StringReader`, `StringWriter` |
| Pipe | `PipedInputStream`, `PipedOutputStream` | `PipedReader`, `PipedWriter` |

### InputStream 주요 메서드

| 메서드 | 설명 |
| --- | --- |
| `abstract int read()` | byte 하나를 읽어 int로 반환. 더 읽을 값이 없으면 **-1** |
| `int read(byte[] b)` | 읽은 데이터로 b를 채우고 읽은 개수 반환. b 길이가 0이면 0, 더 읽을 데이터가 없으면 -1 |
| `int read(byte[] b, int offset, int len)` | 최대 len 만큼 읽어 b의 offset 부터 저장, 읽은 개수 반환 |
| `void close()` | 스트림을 종료해 자원 반납 |

- 모두 `throws IOException`

### Reader 주요 메서드

- InputStream 과 같은 구조, byte 대신 **char** 단위

| 메서드 | 설명 |
| --- | --- |
| `int read()` | char 하나를 읽어 int로 반환. 끝이면 -1 |
| `int read(char[] cbuf)` | cbuf 를 채우고 읽은 문자 개수 반환 |
| `abstract int read(char[] cbuf, int off, int len)` | 최대 len 만큼 읽어 cbuf 의 off 부터 저장 |
| `int read(CharBuffer target)` | target 에 저장 (cbuf 대체) |
| `void close()` | 자원 반납 |

### 예제 — byte 단위 vs char 단위 읽기

- byte 하나씩: 입력의 끝(-1)이 아닐 때까지 계속 읽기
- byte 버퍼 단위: UTF-8 한글은 한 글자가 **3byte** → 버퍼 경계에서 글자가 잘려 깨질 수 있음
- char 버퍼 단위(Reader): 문자 단위라 유니코드가 안전

```java
import java.io.*;

public class ReadTest {
    static String data1 = "hi java";
    static String data2 = "자바는 객체지향 언어입니다.";

    static void read1() {                         // byte 하나씩
        try (InputStream input = new ByteArrayInputStream(data1.getBytes())) {
            int read;
            while ((read = input.read()) != -1) {
                System.out.printf("읽은 값: %d, 문자로: %c%n", read, read);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    static void read2() {                         // byte[10] 단위
        byte[] buffer = new byte[10];
        try (InputStream input = new ByteArrayInputStream(data2.getBytes("UTF-8"))) {
            int read;
            while ((read = input.read(buffer)) > 0) {
                System.out.printf("읽은 개수: %d, 문자열: %s%n", read, new String(buffer, 0, read, "UTF-8"));
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    static void read3() {                         // char[10] 단위
        char[] buffer = new char[10];
        try (Reader input = new CharArrayReader(data2.toCharArray())) {
            int read;
            while ((read = input.read(buffer)) > 0) {
                System.out.printf("읽은 개수: %d, 문자열: %s%n", read, new String(buffer, 0, read));
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    public static void main(String[] args) {
        read1();
        read2();
        read3();
    }
}
/* 출력
읽은 값: 104, 문자로: h
읽은 값: 105, 문자로: i
읽은 값: 32, 문자로:  
읽은 값: 106, 문자로: j
읽은 값: 97, 문자로: a
읽은 값: 118, 문자로: v
읽은 값: 97, 문자로: a
읽은 개수: 10, 문자열: 자바는 
읽은 개수: 10, 문자열: 객체지�
읽은 개수: 10, 문자열: �� 언어�
읽은 개수: 9, 문자열: ��니다.
읽은 개수: 10, 문자열: 자바는 객체지향 언
읽은 개수: 5, 문자열: 어입니다.
*/
```

- `new String(buffer, 0, read)` 처럼 **읽은 개수만큼만** 문자열로 만들어야 함 (버퍼 뒤쪽에 이전 데이터가 남아 있을 수 있음)

> 참고: 교재 read2 는 `new String(buffer)` 로 버퍼 전체를 변환해, 마지막에 9byte 만 읽었을 때 버퍼 끝에 앞 회차의 1byte 가 남아 함께 변환된다. 위 코드는 `0, read` 로 고친 것.

### OutputStream 주요 메서드

| 메서드 | 설명 |
| --- | --- |
| `abstract void write(int b)` | b 를 byte 로 출력 |
| `void write(byte[] b)` | b 전체 출력 |
| `void write(byte[] b, int off, int len)` | b 의 off 부터 len 개 출력 |
| `void close()` | 스트림 종료, 자원 반납. 내부적으로 `flush()` 호출 |
| `void flush()` | 버퍼가 있는 스트림에서 버퍼 내용을 출력하고 비움 |

### Writer 주요 메서드

| 메서드 | 설명 |
| --- | --- |
| `void write(int c)` | c 를 char 로 출력 |
| `void write(char[] cbuf)` | cbuf 출력 |
| `abstract void write(char[] cbuf, int off, int len)` | cbuf 의 off 부터 len 개 출력 |
| `void write(String str)` | str 출력 |
| `void write(String str, int off, int len)` | str 의 off 부터 len 개 출력 |
| `Writer append(CharSequence csq)` | csq 를 출력하고 Writer 반환 (연쇄 호출 가능) |
| `Writer append(CharSequence csq, int start, int end)` | csq 의 start~end 출력 후 Writer 반환 |
| `void close()` | 자원 반납. 내부적으로 `flush()` 호출 |
| `abstract void flush()` | 버퍼 내용을 출력하고 비움 |
