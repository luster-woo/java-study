### File

- 가장 기본적인 입출력 장치 중 하나인 **파일과 디렉터리**를 다루는 클래스
- 파일의 **내용**에는 관여하지 못함 (내용은 스트림으로)

| 메서드 | 설명 |
| --- | --- |
| `File(String pathname)` | pathname 의 File 객체 생성. 경로가 없으면 애플리케이션을 시작한 경로 기준 |
| `File(File parent, String child)` | parent 경로 아래 child |
| `File(URI uri)` | `file:` 로 시작하는 URI 로 생성 |
| `boolean createNewFile()` | 새 물리적 파일 생성 (`throws IOException`) |
| `boolean mkdir()` | 디렉터리 생성 |
| `boolean mkdirs()` | 경로상에 없는 모든 디렉터리 생성 |
| `boolean delete()` | 파일 또는 디렉터리 삭제 |
| `String getName()` | 파일 이름 |
| `String getPath()` | 파일 경로 |
| `String getAbsolutePath()` | 절대 경로 |
| `String getCanonicalPath()` | 정식 경로 — 절대 경로이면서 `.`, `..` 이 없는 경로 (`throws IOException`) |
| `boolean isDirectory()` / `isFile()` | 디렉터리인지 / 파일인지 |
| `long length()` | 파일 길이 |
| `File[] listFiles()` | 디렉터리의 자식 파일들 |

- `new File(...)` 만으로는 실제 파일이 만들어지지 않음 → `createNewFile()`, `mkdirs()` 로 생성

```java
import java.io.*;

public class FileTest {
    public static void main(String[] args) throws IOException {
        File dir = new File("temp" + File.separator + "sub");
        System.out.println(dir.mkdirs());           // true
        File file = new File(dir, "memo.txt");
        System.out.println(file.createNewFile());    // true (이미 있으면 false)
        System.out.println(file.getName());          // memo.txt
        System.out.println(file.getPath());          // temp/sub/memo.txt (Windows는 temp\sub\memo.txt)
        System.out.println(file.isFile() + " " + dir.isDirectory()); // true true
        System.out.println(file.length());           // 0
        File dot = new File("temp/sub/../sub/memo.txt");
        System.out.println(dot.getAbsolutePath().contains(".."));   // true
        System.out.println(dot.getCanonicalPath().contains(".."));  // false
        for (File f : dir.listFiles()) {
            System.out.println("자식: " + f.getName());              // 자식: memo.txt
        }
        System.out.println(file.delete() + " " + dir.delete());     // true true
    }
}
```

- `File.separator`: OS별 경로 구분자 (Windows `\`, Linux/Mac `/`)

### FileInputStream, FileOutputStream

| 생성자 | 설명 |
| --- | --- |
| `FileInputStream(String name)` | name 경로의 파일을 읽는 스트림 |
| `FileOutputStream(String name)` | name 경로의 파일에 출력하는 스트림 (기존 내용 덮어씀) |
| `FileOutputStream(String name, boolean append)` | append 가 true 면 기존 파일 뒤에 이어 씀 |

- 모두 `throws FileNotFoundException`
- `String name` 대신 `File` 객체도 사용 가능
- 버퍼 크기를 바꿔 가며 큰 파일을 복사해 보기

```java
import java.io.*;

public class CopyTest {
    static long fileCopy(File src, File target, int bufferSize) {
        long start = System.currentTimeMillis();
        try (FileInputStream fin = new FileInputStream(src);
             FileOutputStream fout = new FileOutputStream(target)) {
            byte[] buffer = new byte[bufferSize];
            int read;
            while ((read = fin.read(buffer)) > 0) {
                fout.write(buffer, 0, read);      // 읽은 만큼만 쓰기
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
        return System.currentTimeMillis() - start;
    }
    public static void main(String[] args) throws IOException {
        File src = new File("big.bin");
        try (FileOutputStream out = new FileOutputStream(src)) {
            out.write(new byte[5 * 1024 * 1024]);   // 5MB 테스트 파일
        }
        File target = new File("big_copy.bin");
        for (int size : new int[] { 10, 1024, 8192 }) {
            System.out.printf("buffer %5d: %d ms%n", size, fileCopy(src, target, size));
        }
        System.out.println(src.length() == target.length());   // true
    }
}
/* 출력 예 (시간은 실행마다 다름)
buffer    10: 616 ms
buffer  1024: 13 ms
buffer  8192: 6 ms
true
*/
```

- 버퍼가 클수록 read/write 호출 횟수가 줄어 빨라짐

### FileReader, FileWriter

- **문자를 처리할 때는 Reader, Writer** 사용
- 일기장 예제: 키보드 입력 → 파일에 이어 쓰기 → 파일 내용 읽어 콘솔 출력

```
키보드(System.in) → Scanner → FileWriter → diary.txt → FileReader → System.out(콘솔)
```

```java
import java.io.*;
import java.util.*;

public class DiaryTest {
    public static void main(String[] args) {
        File target = new File("diary.txt");
        try (Scanner scanner = new Scanner(System.in);
             FileWriter writer = new FileWriter(target, true);     // true: 이어 쓰기
             FileReader reader = new FileReader(target)) {
            System.out.println("일기를 작성합니다. 그만두려면 x를 입력하세요.");
            writer.write("\n오늘 날짜: " + new Date() + "\n");
            while (true) {
                String str = scanner.nextLine();
                if (str.equals("x")) break;
                writer.write(str + "\n");
            }
            writer.flush();                       // 버퍼 내용을 파일로 내보냄

            char[] buffer = new char[10];
            int read;
            while ((read = reader.read(buffer)) > 0) {
                System.out.print(String.valueOf(buffer, 0, read));
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
/* 입력: 오늘은 입출력 / 스트림 공부 / x  →  출력 (날짜는 실행 시각)
일기를 작성합니다. 그만두려면 x를 입력하세요.

오늘 날짜: Tue Oct 06 22:28:52 KST 2026
오늘은 입출력
스트림 공부
*/
```

- `flush()` 를 하지 않으면 쓴 내용이 아직 파일에 없을 수 있어 reader 가 못 읽음

> 교재 경로는 `c:\Temp\diary.txt` (Windows). 위 코드는 실행 위치 기준 상대 경로로 바꾼 것.

---

## 참고

- 예제 출력은 JDK 11 · Linux 기준. 교재 예제의 `c:\Temp\...` 같은 Windows 절대 경로는 실행 위치 기준 상대 경로로 바꿨음
- 교재 일부 예제에서 버퍼를 `new String(buffer)` 로 통째로 변환하는데, 버퍼 단위로 읽을 때는 항상 `read` 로 받은 개수만큼만 사용
