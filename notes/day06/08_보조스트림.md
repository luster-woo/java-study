### 보조 스트림 (Filter Stream, Processing Stream)

- 다른 스트림에 **부가적인 기능**을 제공하는 스트림

| 구분 | 역할 |
| --- | --- |
| 노드 스트림 | 노드에 연결, 단순한 byte·char 전달 |
| 보조 스트림 | 부가 기능 수행 — 문자 set 변환, Buffering, 기본 데이터형 전송, 객체 입출력 |

- **스트림 체이닝(Stream Chaining)**: 필요에 따라 여러 보조 스트림을 연결해 사용

```
node ── 노드스트림 ── 보조스트림 1 ── 보조스트림 2 ── 프로그램
```

### 보조 스트림의 종류

| 기능 | byte 기반 | char 기반 |
| --- | --- | --- |
| byte 스트림 → char 스트림 변환 | — | `InputStreamReader`, `OutputStreamWriter` |
| 버퍼링을 통한 속도 향상 | `BufferedInputStream`, `BufferedOutputStream` | `BufferedReader`, `BufferedWriter` |
| 객체 전송 | `ObjectInputStream`, `ObjectOutputStream` | — |

- **생성**: 이전 스트림을 생성자의 파라미터로 연결 — **노드 스트림은 언제나 필요**

```java
new BufferedInputStream(System.in);
new ObjectInputStream(new BufferedInputStream(new FileInputStream("data.dat")));
```

- **종료**: 보조 스트림의 `close()` 를 호출하면 연결된 노드 스트림의 `close()` 까지 호출됨

### 사용할 스트림의 결정 과정

```
노드가 무엇인가? → 타입은 문자열인가 바이트인가? → 방향은? → 추가 기능이 필요한가?
└──────────── 노드 스트림 구성 ───────────────┘         └─ 보조 스트림 구성 ─┘
```

| 하고 싶은 일 | 노드 | 타입 | 방향 | 노드 스트림 | 보조 스트림 |
| --- | --- | --- | --- | --- | --- |
| 영화 파일을 빠르게 이동 | File | byte | 읽기 | `FileInputStream` | `BufferedInputStream` |
| | | | 쓰기 | `FileOutputStream` | `BufferedOutputStream` |
| 키보드에서 유니코드 문자를 안전하고 빠르게 읽기 | Keyboard | byte | 읽기 | `System.in` (InputStream) | `InputStreamReader` → `BufferedReader` |
| 메모리의 객체를 파일로 저장 | File | byte | 쓰기 | `FileOutputStream` | `ObjectOutputStream` |
