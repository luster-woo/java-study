## 버전 메모

- 슬라이드 코드는 `javax.persistence` + Hibernate 5 기준. **Spring Boot 3 / Hibernate 6에서는 `jakarta.persistence`** 로 패키지만 바뀌고 개념은 같다.
- 강의 소스코드 `ex1-hello-jpa-start`(2024 시작 프로젝트: Java 17, Hibernate 6.4.2, H2 2.2.224)는 [02장](02_JPA_시작.md#강의-소스코드--2024-최신-버전-시작-프로젝트-ex1-hello-jpa-start)에 정리.
- 강의 자료에 반영된 Hibernate 6 변경점: FROM 절 서브쿼리 지원, 컬렉션 페치 조인 시 `DISTINCT` 없이도 엔티티 중복 자동 제거 → [10장](10_객체지향_쿼리_언어.md) 참고.
- `> 참고:`는 슬라이드에 없는 보충 설명이나 최신 버전 차이를 덧붙인 곳.

## 강의 전체를 관통하는 실무 규칙 10개

1. 엔티티 매니저 팩토리는 하나, 엔티티 매니저는 요청(트랜잭션)마다 쓰고 버린다
2. 데이터 변경은 항상 트랜잭션 안에서
3. 운영 DB에 `create`/`update` DDL 자동 생성 금지 (`validate`/`none`)
4. `@Enumerated`는 무조건 `EnumType.STRING`
5. 기본 키는 `Long` + 대리키 + 자동 생성 전략
6. 연관관계의 주인은 **외래 키가 있는 쪽**(보통 N 쪽). 단방향으로 설계하고 양방향은 필요할 때 추가
7. 양방향이면 양쪽 다 값 세팅 → 연관관계 편의 메서드
8. `@ManyToMany` 쓰지 말고 연결 엔티티로 풀기
9. **모든 연관관계는 지연 로딩(LAZY)**, 필요한 곳만 페치 조인
10. 값 타입은 불변으로, 컬렉션이 복잡해지면 값 타입 컬렉션 대신 일대다 엔티티
