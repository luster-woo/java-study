## 학습 목표

- Java 과목에서 학습한 내용을 적용해 프로젝트 완성
- 파일 입출력으로 데이터를 메모리가 아닌 **파일로 저장/로드**하여 관리

---

## 실습 예제

### 1단계 — SSAFY 교육생 관리 프로그램

- 교육생 정보를 **삽입/조회/수정/삭제** 하는 프로그램 작성
- 먼저 생각해 볼 것
  - 클래스는 어떤 **관계**를 가지는가
  - 어떤 **멤버**를 가져야 하는가
  - 어떤 **기능**을 가져야 하는가

### 2단계 — 재부팅하면 데이터는?

- 컴퓨터를 재부팅했다고 가정 → 1단계 데이터는 **메모리(heap)** 에만 있으므로 프로그램이 끝나면 사라짐
- 해결: **파일로 저장**

### 3단계 — 파일로 저장 및 관리

- 교육생 정보를 삽입/조회/수정/삭제하고, 그 데이터를 **파일로 저장·관리**하는 프로그램으로 확장

---

## 풀이 예시

> 교재 정답이 아니라 요구사항에 맞춰 직접 작성한 예시 코드임.

### 설계

| 클래스 | 역할 | 사용한 Java 내용 |
|---|---|---|
| `Student` | 교육생 데이터 (학번·이름·캠퍼스·반) | 캡슐화, `toString` 재정의, `Serializable` |
| `StudentManager` | 교육생 목록 CRUD + 파일 저장/로드 | 싱글턴, `List`/`ArrayList`, 객체 스트림 |
| `StudentNotFoundException`, `DuplicateStudentException` | 없는 학번 / 중복 학번 | 사용자 정의 예외, `throws` |
| `StudentApp` | 메뉴 입력을 받아 Manager 호출 | `Scanner`, `switch`, multi-catch |

```
StudentApp ──uses──> StudentManager ──has-a──> List<Student>
                          │
                          └── save() / load() ──> students.dat (ObjectOutputStream / ObjectInputStream)
```

- 학번을 키로 사용 → 중복 등록은 예외, 없는 학번 조회·수정·삭제도 예외
- 1단계(메모리)와 3단계(파일)의 차이는 `StudentManager` 의 `save()`·`load()` 두 메서드뿐
  - **생성자에서 `load()`** → 시작할 때 파일 내용을 List로 복원
  - **종료 메뉴에서 `save()`** → List 전체를 파일에 기록

### 코드

```java
import java.io.*;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class StudentApp {
    public static void main(String[] args) {
        StudentManager sm = StudentManager.getInstance();
        Scanner sc = new Scanner(System.in);

        while (true) {
            System.out.println("1.등록 2.전체조회 3.학번조회 4.수정 5.삭제 0.종료");
            int menu = Integer.parseInt(sc.nextLine().trim());
            try {
                switch (menu) {
                    case 1:
                        String[] in = sc.nextLine().split(",");   // 학번,이름,캠퍼스,반
                        sm.add(new Student(in[0], in[1], in[2], Integer.parseInt(in[3])));
                        break;
                    case 2:
                        for (Student s : sm.getList()) System.out.println(s);
                        break;
                    case 3:
                        System.out.println(sm.get(sc.nextLine().trim()));
                        break;
                    case 4:
                        String[] up = sc.nextLine().split(",");   // 학번,캠퍼스,반
                        sm.update(up[0], up[1], Integer.parseInt(up[2]));
                        break;
                    case 5:
                        sm.remove(sc.nextLine().trim());
                        break;
                    case 0:
                        sm.save();                                 // 종료 시 파일에 저장
                        System.out.println("저장 후 종료");
                        return;
                }
            } catch (StudentNotFoundException | DuplicateStudentException e) {
                System.out.println("[오류] " + e.getMessage());
            }
        }
    }
}

class Student implements Serializable {             // 객체를 파일에 쓰려면 직렬화 가능해야 함
    private static final long serialVersionUID = 1L;
    private String id;        // 학번
    private String name;
    private String campus;
    private int classNum;     // 반

    public Student(String id, String name, String campus, int classNum) {
        this.id = id;
        this.name = name;
        this.campus = campus;
        this.classNum = classNum;
    }

    public String getId() { return id; }
    public void setCampus(String campus) { this.campus = campus; }
    public void setClassNum(int classNum) { this.classNum = classNum; }

    @Override
    public String toString() {
        return "Student [id=" + id + ", name=" + name + ", campus=" + campus + ", class=" + classNum + "]";
    }
}

class StudentNotFoundException extends Exception {
    public StudentNotFoundException(String id) {
        super(id + " 학번의 교육생이 없습니다.");
    }
}

class DuplicateStudentException extends Exception {
    public DuplicateStudentException(String id) {
        super(id + " 학번은 이미 등록되어 있습니다.");
    }
}

class StudentManager {
    private static final String FILE = "students.dat";
    private static StudentManager instance = new StudentManager();

    private List<Student> list = new ArrayList<>();   // 배열 대신 크기가 자동으로 늘어나는 List

    private StudentManager() {
        load();                                         // 프로그램 시작 시 파일에서 읽어 옴
    }

    public static StudentManager getInstance() {
        return instance;
    }

    public void add(Student s) throws DuplicateStudentException {
        if (find(s.getId()) != null) throw new DuplicateStudentException(s.getId());
        list.add(s);
    }

    public List<Student> getList() {
        return new ArrayList<>(list);                   // 복사본을 넘겨 외부에서 원본 목록을 못 바꾸게 함
    }

    public Student get(String id) throws StudentNotFoundException {
        Student s = find(id);
        if (s == null) throw new StudentNotFoundException(id);
        return s;
    }

    public void update(String id, String campus, int classNum) throws StudentNotFoundException {
        Student s = get(id);
        s.setCampus(campus);
        s.setClassNum(classNum);
    }

    public void remove(String id) throws StudentNotFoundException {
        list.remove(get(id));
    }

    private Student find(String id) {
        for (Student s : list) {
            if (s.getId().equals(id)) return s;
        }
        return null;
    }

    // 메모리(List) → 파일
    public void save() {
        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream(FILE))) {
            oos.writeObject(list);                      // ArrayList 도 Serializable
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // 파일 → 메모리(List)
    @SuppressWarnings("unchecked")
    private void load() {
        File f = new File(FILE);
        if (!f.exists()) return;                        // 첫 실행: 저장된 파일 없음
        try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream(f))) {
            list = (List<Student>) ois.readObject();
        } catch (IOException | ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}
```

## 참고

- 직렬화 조건은 [보조스트림 활용](../day06/09_보조스트림_활용.md) 참고 — `Student` 의 멤버(`String`, `int`)와 `ArrayList` 모두 직렬화 가능하므로 `List` 를 통째로 `writeObject` 가능
- `serialVersionUID` 를 지정하지 않으면 `Student` 클래스를 고친 뒤 예전 파일을 읽을 때 `InvalidClassException` 이 날 수 있음
- 이 예시는 종료(0)할 때만 저장 → 강제 종료하면 그 실행에서 바꾼 내용은 사라짐. 등록·수정·삭제마다 `save()` 를 호출하는 방식도 가능
- 객체 스트림 대신 텍스트(CSV)나 [JSON](../day06/10_JSON.md) 으로 저장하면 파일을 사람이 직접 읽을 수 있음
