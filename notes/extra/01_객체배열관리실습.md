## 실습 예제

### Person Manager 실습

- 사람들을 **관리(추가, 조회, 수정, 삭제)** 하는 프로그램 작성
- **싱글턴 패턴** 적용
- 교재 그림: `Person` 객체의 **주소**를 담는 배열(목록) — 앞쪽부터 채워지고 나머지 칸은 `null`

```
목록(Person[])
┌─────┬─────┬─────┬──────┬──────┬──────┬──────┐
│ 0x1 │ 0x2 │ 0x3 │ null │ null │ null │ null │
└──┬──┴──┬──┴──┬──┴──────┴──────┴──────┴──────┘
   ▼     ▼     ▼
 Person Person Person      ← 배열에는 객체가 아니라 참조(주소)가 들어 있음
```

### 생각할 점

| 기능 | 배열로 처리하는 방법 |
|---|---|
| 추가 | 몇 칸 찼는지 세는 `size` 변수 → `arr[size++] = p` |
| 전체 조회 | `0 ~ size-1` 까지만 반복 (뒤쪽 `null` 칸 제외) |
| 조회·수정 | 이름이 같은 객체의 **인덱스**를 찾아 사용 |
| 삭제 | 찾은 위치 뒤의 원소를 한 칸씩 **앞으로 당기고** 마지막 칸을 `null` |
| 싱글턴 | 관리 객체(PersonManager)는 프로그램 전체에서 **하나만** 존재 |

## 풀이 예시

> 교재 정답이 아니라 요구사항(객체배열 CRUD + 싱글턴)에 맞춰 직접 작성한 예시 코드임.

- `Person` — 이름·나이를 가진 데이터 클래스
- `PersonManager` — `Person[]` 과 `size` 로 CRUD, 싱글턴(`private` 생성자 + `static getInstance()`)
- 이름을 키로 사용 → `indexOf(name)` 하나를 조회·수정·삭제가 함께 사용

```java
import java.util.Arrays;

public class PersonTest {
    public static void main(String[] args) {
        PersonManager pm = PersonManager.getInstance();
        System.out.println(pm == PersonManager.getInstance());   // true (싱글턴 확인)

        // 추가(Create)
        pm.add(new Person("홍길동", 25));
        pm.add(new Person("김싸피", 27));
        pm.add(new Person("이자바", 30));
        printAll(pm);

        // 조회(Read)
        System.out.println(pm.get("김싸피"));   // Person [name=김싸피, age=27]
        System.out.println(pm.get("박없음"));   // null

        // 수정(Update)
        System.out.println(pm.update(new Person("김싸피", 28)));  // true
        System.out.println(pm.get("김싸피"));   // Person [name=김싸피, age=28]

        // 삭제(Delete)
        System.out.println(pm.remove("홍길동"));   // true
        System.out.println(pm.remove("박없음"));   // false
        printAll(pm);
    }

    static void printAll(PersonManager pm) {
        System.out.println("--- 목록 (" + pm.size() + "명) ---");
        for (Person p : pm.getAll()) {
            System.out.println(p);
        }
    }
}

class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }

    @Override
    public String toString() {
        return "Person [name=" + name + ", age=" + age + "]";
    }
}

class PersonManager {
    private static final int MAX_SIZE = 100;
    private Person[] persons = new Person[MAX_SIZE];
    private int size = 0;                       // 들어 있는 사람 수 = 다음에 넣을 인덱스

    // 싱글턴 1) 자기 자신을 private static 으로 하나 만들어 둠
    private static PersonManager instance = new PersonManager();
    // 싱글턴 2) 외부에서 new 금지
    private PersonManager() {}
    // 싱글턴 3) 공유 객체를 꺼내 주는 static getter
    public static PersonManager getInstance() {
        return instance;
    }

    public int size() { return size; }

    // 추가: size 위치에 넣고 size 증가
    public boolean add(Person p) {
        if (size == MAX_SIZE) {
            System.out.println("더 이상 추가할 수 없습니다.");
            return false;
        }
        persons[size++] = p;
        return true;
    }

    // 전체 조회: null 칸을 빼고 실제 데이터만 복사해서 반환
    public Person[] getAll() {
        return Arrays.copyOf(persons, size);
    }

    // 이름으로 위치 찾기 (없으면 -1)
    private int indexOf(String name) {
        for (int i = 0; i < size; i++) {
            if (persons[i].getName().equals(name)) {
                return i;
            }
        }
        return -1;
    }

    public Person get(String name) {
        int idx = indexOf(name);
        return idx == -1 ? null : persons[idx];
    }

    // 수정: 같은 이름을 찾아 나이 변경
    public boolean update(Person p) {
        int idx = indexOf(p.getName());
        if (idx == -1) return false;
        persons[idx].setAge(p.getAge());
        return true;
    }

    // 삭제: 뒤 원소를 한 칸씩 앞으로 당기고 마지막 칸은 null
    public boolean remove(String name) {
        int idx = indexOf(name);
        if (idx == -1) return false;
        for (int i = idx; i < size - 1; i++) {
            persons[i] = persons[i + 1];
        }
        persons[--size] = null;
        return true;
    }
}
```

### 삭제 과정 (홍길동 삭제)

```
삭제 전  [홍길동][김싸피][이자바][null] ...   size = 3
당기기   [김싸피][이자바][이자바][null] ...   (i=0,1 에서 한 칸씩 앞으로)
정리     [김싸피][이자바][null ][null] ...   persons[--size] = null → size = 2
```

## 참고

- `getAll()` 에서 `persons` 배열을 그대로 반환하면 호출한 쪽이 배열 칸을 바꿀 수 있음 → `Arrays.copyOf` 로 **복사본** 반환 (안의 Person 객체는 같은 참조)
- 마지막 칸을 `null` 로 지우지 않으면 삭제된 객체를 배열이 계속 참조함 → GC 대상이 되지 못함
- 싱글턴 작성 방법은 [encapsulation](../day03/05_encapsulation.md) 의 Singleton 디자인 패턴 참고
