## 위치에 따른 변수의 종류

### 타입에 따른 분류

| 변수 종류 | 특징 | 예 |
|---|---|---|
| Primitive Type variable | 기본 8가지 type의 변수 | `int i`, `char c`, `float f` … |
| Reference Type variable | 나머지 모든 것(객체 참조) | `String s`, `int[] points`, `Person p` … |

### 선언 위치에 따른 분류

| 종류 | 선언 위치 | 변수 종류 |
|---|---|---|
| 멤버 변수 | 클래스 영역 (`static` keyword) | **클래스 멤버 변수** |
| 멤버 변수 | 클래스 영역 | **인스턴스 멤버 변수** |
| 지역 변수 | 함수 내부 | **지역 변수** |
| 지역 변수 | 함수 선언부 | **파라미터 변수** |

```java
public class VariableTypes {
    int instanceVariable;        // 인스턴스 멤버 변수
    static int classVariable;    // 클래스 멤버 변수

    public static void main(String[] args) {  // args : 파라미터 변수
        int localVariable = 10;               // 로컬 변수
        for (int i = 0; i < 100; i++) {       // i : 로컬 변수
            System.out.println(i);
        }
    }
}
```

### 인스턴스 멤버 변수의 특징

- **선언 위치** : 클래스 `{ }` 영역에 선언
- **생성** : 객체가 만들어질 때 heap에 **객체별로** 생성
- **초기화** : 타입별 default 초기화 → 할당된 값으로 명시적 초기화
- **접근** : 객체 생성 후(메모리에 올린 후) **객체 이름(소속)**으로 접근
  - 객체마다 생성되므로 객체마다 고유한 상태(변수 값) 유지
- **소멸** : Garbage Collector에 의해 객체가 없어질 때 (프로그래머가 명시적으로 소멸 불가)

```java
public class Person {
    String name;
    int age = 10;
}
```

```java
Person person1 = new Person();
person1.name = "홍길동";
Person person2 = new Person();
person2.name = "임꺽정";
```

### 클래스 멤버 변수의 특징

- **선언 위치** : 클래스 `{ }` 영역에 선언, **`static`** 키워드를 붙임
- **생성** : 클래스 로더에 의해 클래스가 로딩될 때 구성 — 값은 heap 영역에
- 개별 객체 생성과 무관하며 **모든 객체가 공유** (공유 변수라고도 부름)
- **초기화** : 타입별 default 초기화 후 할당된 값으로 명시적 초기화
- **접근** : 객체 생성과 무관하게 **클래스 이름(소속)**으로 접근
  - 객체 이름으로도 접근은 되지만 static에 부합한 표현이 아님 (경고)
- **소멸** : 클래스가 언로드될 때 함께 제거

```java
public class Person {
    static String scientificName = "Homo Sapiens";
    String name;
}
```

```java
Person p = new Person();
p.scientificName = "객체를 통한 변경";
// 경고: The static field Person.scientificName should be accessed in a static way
Person.scientificName = "클래스를 통한 변경";   // 권장
```

### 지역 변수 & 파라미터 변수

- **선언 위치** : 클래스 영역의 `{ }` 이외의 모든 중괄호 안 — 메서드, 생성자, 초기화 블록
- **생성** : 선언된 라인이 실행될 때 / 메모리 영역 : **stack의 메서드 프레임 내부**
- **초기화** : 사용 전 **명시적 초기화 필요** (기본값 없음)
- **접근** : 외부에서 접근 불가 → 소속 불필요, 내부에서 이름으로 바로 접근
- **소멸** : 선언된 영역 `{ }`을 벗어날 때

```java
void call(String to) {              // 파라미터 변수
    String beep = "띠";              // 로컬 변수
    for (int i = 0; i < 3; i++) {   // 로컬 변수
        System.out.println(beep);
    }
}
```

### 정리 — 변수 종류별 비교

| | 클래스 멤버 변수 | 인스턴스 멤버 변수 | 지역·파라미터 변수 |
|---|---|---|---|
| 선언 | 클래스 영역 + `static` | 클래스 영역 | 메서드·생성자·블록 안 |
| 생성 시점 | 클래스 로딩 시 | 객체 생성 시 | 선언 라인 실행 시 |
| 위치 | heap (교재 기준) | heap (객체 안) | stack (메서드 프레임) |
| 초기화 | default → 명시적 | default → 명시적 | 명시적 초기화 필수 |
| 접근 | `클래스이름.변수` | `객체이름.변수` | 이름으로 바로 |
| 소멸 | 클래스 언로드 시 | GC가 객체 정리 시 | `{ }` 벗어날 때 |

### 손컴파일링 — 메모리 동작 그려보기

```java
// SmartPhoneTest.java
public class SmartPhoneTest {
    public static void main(String[] args) {
        SmartPhone sphone = new SmartPhone();
        sphone.number = "010";
        System.out.println(SmartPhone.osVer + " : " + sphone.number);  // 1.0 : 010
        sphone.call("011");                                             // 띠 (3번 출력)

        SmartPhone sphone2 = new SmartPhone();
        sphone2.number = "010-111-1111";
        System.out.println(SmartPhone.osVer + " : " + sphone2.number); // 1.0 : 010-111-1111

        SmartPhone.osVer = 2.0;  // 클래스 이름으로 변경 -> 모든 객체가 공유
        System.out.println(sphone.osVer + " : " + sphone.number);      // 2.0 : 010
    }
}

class SmartPhone {
    static double osVer = 1.0;   // 클래스 멤버 변수
    String number;               // 인스턴스 멤버 변수

    void call(String to) {       // to : 파라미터 변수
        String msg = "띠";        // 로컬 변수
        for (int i = 0; i < 3; i++) { // i : 로컬 변수
            System.out.println(msg);
        }
    }
}
```

```
metaspace                    stack                          heap
---------                    -----                          ----
SmartPhone                   [call] to, msg, i  (call 끝나면 제거)
 - osVer (공유) 1.0 -> 2.0   [main] sphone  -> 0x100         0x100 : number = "010"
 - call()                           sphone2 -> 0x200         0x200 : number = "010-111-1111"
SmartPhoneTest - main()
```

- 교재 원본은 `sphone.osVer`처럼 객체로 접근 — 동작은 하지만 경고 대상이라 위 코드는 앞 두 줄을 클래스 이름으로 씀
- `osVer`는 객체가 아닌 클래스에 하나만 있으므로 `SmartPhone.osVer = 2.0` 이후 `sphone.osVer`도 2.0

## 참고

- 클래스 멤버 변수 위치 : 이 교재는 "값은 heap 영역에", 비전공반 교재(객체배열관리)는 "메서드 영역에 저장"으로 설명함. JVM 명세상 static 변수는 메서드 영역(클래스 정보)에 속한 개념이고, HotSpot JVM(Java 8+)은 실제 값을 heap의 클래스 객체에 둠 — 둘 다 "JVM 버전에 따라 달라질 수 있다"는 교재 단서의 범위
