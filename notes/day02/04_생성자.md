## 생성자

- 객체를 생성할 때 호출하는 **메서드 비슷한 것**
  - **`new`** 키워드와 함께 호출 : `Person person1 = new Person();`
  - 일반 멤버 변수의 초기화나 객체 생성 시 실행돼야 하는 작업 정리
- **작성 규칙** : 메서드와 비슷하나 **리턴 타입이 없고 이름은 클래스 이름과 동일**

```java
제한자 클래스_명(타입 변수_명, 타입 변수_명 ...) {   // 선언부
    // 멤버 변수 초기화 작업                          // 구현부
}
```

## 생성자의 종류

### 기본 생성자 (default constructor)

- 그동안 예제에서는 생성자를 작성하지 않았음
- 기본 생성자 형태 : **파라미터가 없고 구현부가 비어 있음**
- 생성자 코드가 없으면 **컴파일러가 기본 생성자 제공**

```java
public class DefaultPerson {
    String name;
    int age;
    boolean isHungry;
    // public DefaultPerson() {}  -- 생략된 기본 생성자

    public static void main(String[] args) {
        DefaultPerson person = new DefaultPerson();
        person.name = "홍길동";
        person.age = 10;
        person.isHungry = false;
    }
}
```

### 파라미터가 있는 생성자

- 생성자의 목적 = 일반 멤버 변수의 초기화 → 생성자 호출 시 값을 넘겨서 초기화
- **주의** : 파라미터가 있는 생성자를 만들면 **기본 생성자는 추가되지 않음**

```java
public class ParameterPerson {
    String name;
    int age;
    boolean isHungry;

    // 생성자의 역할 : member 변수의 초기화
    ParameterPerson(String n, int a, boolean i) {
        name = n;
        age = a;
        isHungry = i;
    }

    public static void main(String[] args) {
        ParameterPerson person = new ParameterPerson("홍길동", 10, true);
        ParameterPerson p2 = new ParameterPerson();   // 컴파일 오류: 기본 생성자 없음
    }
}
```

## this의 용법

### this.

- **참조 변수로써 객체 자신**을 가리킴
  - 참조 변수로 객체 멤버에 접근하듯 `this`로 자신의 멤버에 접근
- **용도**
  - 로컬 변수와 멤버 변수 이름이 같을 때 **멤버 변수임을 명시**
  - 명시적으로 멤버임을 나타낼 때

```java
public class Person {
    String name = "아무개";
    int age = 0;
    boolean isHungry = true;

    Person(String name, int age, boolean isHungry) {
        this.name = name;          // this.name = 멤버, name = 파라미터
        this.age = age;
        this.isHungry = isHungry;
    }

    void walk() {
        this.isHungry = true;
        System.out.println("뚜벅뚜벅");
    }
}
```

- `this`는 **객체에 대한 참조** → **static 영역에서 this 사용 불가**

```java
public static void main(String[] args) {
    ThisPerson person = new ThisPerson("홍길동", 20, true);
    System.out.println(person.getPersonInfo());
    System.out.println(this.name);   // 컴파일 오류: Cannot use this in a static context
}
```

### this()

- 메서드처럼 **생성자도 오버로딩 가능**
  - 객체 생성 시 필요한 멤버 변수만 초기화 → 생성자별 코드 중복 발생
  - **한 생성자에서 다른 생성자를 호출**할 때 `this()` 사용
- **반드시 첫 줄에서만** 호출 가능

| 중복 있음 | `this()`로 중복 제거 |
|---|---|
| `(String name)` 안에서 `this.name = name;` | `this(name, 0);` |
| `()` 안에서 `this.name = "홍길동"; this.age = 100;` | `this("홍길동", 100);` |

```java
public class OverloadConstructorPerson {
    String name = "아무개";
    int age = 0;

    OverloadConstructorPerson(String name, int age) {
        this.name = name;
        this.age = age;
    }

    OverloadConstructorPerson(String name) {
        this(name, 0);
    }

    OverloadConstructorPerson() {
        // 첫 번째 라인에서만 사용 가능
        this("홍길동", 100);
    }

    String getPersonInfo() {
        return this.name + " " + this.age;
    }

    public static void main(String[] args) {
        System.out.println(new OverloadConstructorPerson("임꺽정", 20).getPersonInfo()); // 임꺽정 20
        System.out.println(new OverloadConstructorPerson("장길산").getPersonInfo());     // 장길산 0
        System.out.println(new OverloadConstructorPerson().getPersonInfo());             // 홍길동 100
    }
}
```

## APPENDIX: 초기화 블록

## 초기화 블록 (Initializer)

- 생성자처럼 **멤버 변수의 초기화**가 목적
  - `{ }` 안에 실행 코드 작성
  - 이름이 없어 별도로 호출할 수 없고 파라미터도 받을 수 없음

| 종류 | 형태 | 용도 | 호출 시점 |
|---|---|---|---|
| **클래스 초기화 블록** | `static { }` | 클래스 멤버 변수 초기화 | 클래스 로딩 시 **1회** |
| **인스턴스 초기화 블록** | `{ }` | 인스턴스 멤버 변수 초기화 | 객체 생성 시마다 1회, **생성자 코드보다 먼저** |

```
클래스 로딩 -> 클래스 초기화 블록
객체 생성(new) -> 인스턴스 초기화 블록 -> 생성자 코드
```

```java
public class InitializerTest {
    int iv;
    static int cv;

    static {
        System.out.println("static initializer");
        cv = 100;
    }

    {
        System.out.println("instance initializer");
        iv = 100;
    }

    public InitializerTest() {
        System.out.printf("생성자- iv: %d, cv: %d%n", iv, cv);
        this.iv = 300;
    }

    public static void main(String[] args) {
        InitializerTest it = new InitializerTest();
        System.out.printf("1 - cv: %d, iv: %d%n", cv, it.iv);
        InitializerTest it2 = new InitializerTest();
        System.out.printf("2 - cv: %d, iv: %d%n", cv, it2.iv);
    }
}
/* 출력
static initializer
instance initializer
생성자- iv: 100, cv: 100
1 - cv: 100, iv: 300
instance initializer
생성자- iv: 100, cv: 100
2 - cv: 100, iv: 300
*/
```

- static 블록은 한 번만, 인스턴스 블록은 `new`마다 실행됨

## 구성요소의 로딩 순서

| Static 요소의 로딩 | Instance 요소의 로딩 |
|---|---|
| 1. Static 변수 로딩 → 기본 초기화 | 1. 멤버 변수 로딩 → 기본 초기화 |
| 2. Static Method 로딩 | 2. Instance Initializer 실행 |
| 3. Static Initializer 실행 | 3. 생성자 호출 |
| 4. Static Method 중 main 실행 | |

```java
public class LoadingSequenceTest {
    static int SIZE;
    static int[] sArray = new int[SIZE];
    int[] iArray = new int[SIZE];

    static { SIZE = 10; }
    { SIZE = 2; }

    public LoadingSequenceTest() {
        SIZE = 1;
    }

    public static void main(String[] args) {
        System.out.println("SIZE: %d".formatted(SIZE));                     // SIZE: 10
        LoadingSequenceTest lst = new LoadingSequenceTest();
        System.out.println("sArray 길이: %d".formatted(sArray.length));      // sArray 길이: 0
        System.out.println("SIZE: %d".formatted(SIZE));                     // SIZE: 1
        System.out.println("iArray 길이: %d".formatted(lst.iArray.length)); // iArray 길이: 10
    }
}
```

- `sArray` : static 블록(`SIZE = 10`)보다 **위에** 있어 SIZE가 아직 0일 때 생성 → 길이 0
- `main` 시작 시점엔 static 블록이 끝나 SIZE = 10
- `iArray` : 객체 생성 시 인스턴스 블록(`SIZE = 2`)보다 먼저 생성 → 그때 SIZE는 10 → 길이 10
- 그 뒤 인스턴스 블록(2) → 생성자(1) 순으로 실행 → 마지막 SIZE = 1

## 참고

- 로딩 순서 표의 "변수 로딩 → 초기화 블록" 구분은 기본값 기준. 실제로는 `static int[] sArray = new int[SIZE];` 같은 **명시적 초기화와 static 블록이 소스에 적힌 순서대로** 실행됨(인스턴스 쪽도 같음) — 그래서 위 예제에서 sArray 길이가 0
- `"...".formatted()`는 Java 15+, switch 식(`->`, `yield`)은 Java 14+ 문법
